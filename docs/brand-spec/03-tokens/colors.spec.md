## 2. Acessibilidade & Contraste (WCAG 2.1 AAA)

- **Contraste Mínimo:** Texto Alabaster (`#FAF7F5`) sobre Fundo Obsidian (`#0D0A0F`) possui razão de contraste de **17.8:1** (Supera o requisito AAA de 7:1).
- **Contraste de Botão CTA:** Texto Branco sobre Crimson (`#E11D48`) possui contraste de **4.6:1** (Em conformidade com requisito AA para botões interativos).
