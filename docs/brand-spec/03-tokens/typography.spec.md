---

## 1. Font Stack Oficial

```css
:root {
  /* Marca e Titulos Editoriais */
  --font-brand: 'Playfair Display', Georgia, serif;
  
  /* Interface do Usuário (UI/UX) */
  --font-sans: 'Plus Jakarta Sans', -apple-system, BlinkMacSystemFont, sans-serif;
  
  /* Dados Financeiros, SKUs e Métricas */
  --font-mono: 'JetBrains Mono', monospace;
}
```

---

## 2. Escala Tipográfica (Type Scale)

- **Display H1 (Hero Title):** Playfair Display Bold 700 / $44\text{px}$ – $52\text{px}$ / Line-height $1.1$
- **H2 Section Title:** Playfair Display SemiBold 600 / $28\text{px}$ – $32\text{px}$ / Line-height $1.2$
- **H3 Card Title:** Plus Jakarta Sans Bold 700 / $18\text{px}$ – $20\text{px}$ / Line-height $1.3$
- **Body Regular:** Plus Jakarta Sans Medium 500 / $15\text{px}$ – $16\text{px}$ / Line-height $1.6$
- **Caption / Meta:** Plus Jakarta Sans Regular 400 / $12\text{px}$ – $13\text{px}$ / Line-height $1.4$
- **SKU / Price Mono:** JetBrains Mono SemiBold 600 / $14\text{px}$ / Line-height $1.2$
