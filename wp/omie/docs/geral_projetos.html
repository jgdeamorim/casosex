Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarProjeto

Altera um projeto

Parâmetros:
  projAlterarRequest projAlterarRequest
Solicitação de Alteração de um projeto
Retorno projAlterarResponse:
Exemplo:
{
   "codigo": 0, 
   "codint": "123",
   "nome": "",
   "inativo": "N"
}

ConsultarProjeto

Consulta um projeto

Parâmetros:
  projConsultarRequest projConsultarRequest
Solicitação da Consulta de projeto
Retorno projConsultarResponse: Resposta da Consulta de Projeto
Exemplo:
{
   "codigo": 0,
   "codint": "123"
}

ExcluirProjeto

Exclui um projeto

Parâmetros:
  projExcluirRequest projExcluirRequest
Solicitação de Exclusão de um projeto.
Retorno projExcluirResponse:
Exemplo:
{
   "codigo": 0,
   "codint": "123"
}

IncluirProjeto

Inclui um novo projeto

Parâmetros:
  projIncluirRequest projIncluirRequest
Solicitação de Inclusão de um projeto
Retorno projIncluirResponse:
Exemplo:
{
   "codint": "123",
   "nome": "",
   "inativo": "N"
}

ListarProjetos

Lista os projetos cadastrados

Parâmetros:
  projListarRequest projListarRequest
Solicitação de Listagem de Projetos
Retorno projListarResponse: Resposta da listagem de Projetos
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 50,
  "apenas_importado_api": "N"
}

UpsertProjeto

Inclui / Altera um projeto.

Parâmetros:
  projUpsertRequest projUpsertRequest
Solicitação de Inclusão/Alteração de um projeto
Retorno projUpsertResponse:
Exemplo:
{
   "codigo": 0, 
   "codint": "123",
   "nome": "",
   "inativo": "N"
}
