Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarCenarios

Parâmetros:
  cenariosListarRequest cenariosListarRequest
Solicitação de listagem de Cenários de Impostos.
Retorno cenariosListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20,
  "cNome": ""
}

ListarImpostosCenario

Parâmetros:
  cenariosImpostosListarRequest cenariosImpostosListarRequest
Solicitação de listagem dos Impostos do Cenário para o produto e cliente.
Retorno cenariosImpostosListarResponse:
Exemplo:
{
    "codigo_cliente_integracao": "CLI00001",
    "consumo_final": "N",
    "codigo_produto_integracao": "PRD00001",
    "codigo_cenario": 152055
  }
