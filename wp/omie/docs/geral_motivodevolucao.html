Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarMotivosDevol

Parâmetros:
  ListarMotivoDevolRequest ListarMotivoDevolRequest
Solicitação da listagem de motivos de devolução.
Retorno ListarMotivoDevolResponse:
Exemplo:
{
   "nPagina": 1,
   "nRegPorPagina": 20
}

Tipos Complexos

ListarMotivoDevolRequest

nPagina integer
Número da página retornada
nRegPorPagina integer
Número de registros retornados na página.

ListarMotivoDevolResponse

nPagina integer
Número da página retornada
nTotPaginas integer
Número total de páginas
nRegistros integer
Número de registros retornados na página.
nTotRegistros integer
total de registros encontrados
listaMotivo listaMotivoArray
Lista os cadastros encontrados.

listaMotivo

Lista os cadastros encontrados.

nCodigo integer
Código do motivo da devolução.
cDescricao string150
Descrição do motivo da devolução.
cInativo string1
Indica se o motivo da devolução está inativo.
+
Pode ser "S" ou "N".

listaMotivoArray

Este parâmetro é um array do tipo listaMotivo
