Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarNFSEs

Lista de NFS-es.

Parâmetros:
  nfseListarRequest nfseListarRequest
Solicitação de listagem de NFS-es emitidas.
Retorno nfseListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20
}
