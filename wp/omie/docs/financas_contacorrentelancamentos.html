Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarLancCC

Parâmetros:
  lanccAlterarRequest lanccAlterarRequest
Solicitação de alteração de um lançamento do conta corrente
Retorno lanccAlterarResponse:
Exemplo:
{
  "cCodIntLanc": "1788306290",
  "cabecalho": 
  {
    "nCodCC": 427619317,
    "dDtLanc": "01/09/2026",
    "nValorLanc": 123.46  
  },
  "detalhes":
  {
    "cCodCateg": "1.01.02",
    "cTipo": "DIN", 
    "nCodCliente": 2485994, 
    "cObs": "Referente a jardinagem executada na matriz"
  } 
}

ConsultaLancCC

Parâmetros:
  lanccConsultarRequest lanccConsultarRequest
Solicitação da consulta de um lançamento do conta corrente
Retorno lanccConsultarResponse:
Exemplo:
{
  "nCodLanc": 0,
  "cCodIntLanc": ""
}

ExcluirLancCC

Parâmetros:
  lanccExcluirRequest lanccExcluirRequest
Solicitação de exclusão de um lançamento do conta corrente
Retorno lanccExcluirResponse:
Exemplo:
{
  "nCodLanc": 0,
  "cCodIntLanc": ""
}

ListarLancCC

Parâmetros:
  lanccListarRequest lanccListarRequest
Solicitação de listagem de lançamentos da conta corrente
