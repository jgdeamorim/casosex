Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCaractCliente

Parâmetros:
  AlterarCaractClienteRequest AlterarCaractClienteRequest
Altera uma característica de um cliente/fornecedor.
Retorno AlterarCaractClienteResponse:
Exemplo:
{
  "codigo_cliente_omie": 0,
  "codigo_cliente_integracao": "",
  "campo": "",
  "conteudo": ""
}

ConsultarCaractCliente

Parâmetros:
  ConsultarCaractClienteRequest ConsultarCaractClienteRequest
Consulta todas as características de um cliente/fornecedor.
Retorno ConsultarCaractClienteResponse:
Exemplo:
{
  "codigo_cliente_omie": 0,
  "codigo_cliente_integracao": ""
}

ExcluirCaractCliente

Parâmetros:
  ExcluirCaractClienteRequest ExcluirCaractClienteRequest
Exclui uma característica de um cliente/fornecedor.
Retorno ExcluirCaractClienteResponse:
Exemplo:
{
  "codigo_cliente_omie": 0,
  "codigo_cliente_integracao": "",
  "campo": ""
}

ExcluirTodasCaractCliente

Parâmetros:
  ExcluirTodasCaractClienteRequest ExcluirTodasCaractClienteRequest
Exclui todas as características de um cliente/fornecedor.
Retorno ExcluirTodasCaractClienteResponse:
Exemplo:
{
  "codigo_cliente_omie": 0,
  "codigo_cliente_integracao": ""
}

IncluirCaractCliente

Parâmetros:
  IncluirCaractClienteRequest IncluirCaractClienteRequest
Inclui uma característica de um cliente/fornecedor.
Retorno IncluirCaractClienteResponse:
Exemplo:
{
  "codigo_cliente_omie": 0,
  "codigo_cliente_integracao": "",
  "campo": "",
  "conteudo": ""
}

codigo_cliente_omie integer

campo string30
Nome da característica.
+
Preenchimento obrigatório.
Caso não encontre a característica um novo cadastro será adicionado.
conteudo string60
Conteúdo do característica.
+
Preenchimento obrigatório na inclusão.

Caso o valor desse campo não seja informado a característica
será excluída para o cliente/fornecedor.
