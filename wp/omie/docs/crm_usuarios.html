Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarUsuarios

Parâmetros:
  uscrmListarRequest uscrmListarRequest
Solicitação da listagem de usuários / vendedores / prevendas.
Retorno uscrmListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}

ObterUsuarios

Parâmetros:
  obterUsuariosRequest obterUsuariosRequest
Solicitação do cadastro de usuários / vendedores / prevendas.
Retorno obterUsuariosResponse:
Exemplo:
{
   "cExibirTodos": "N"
}
