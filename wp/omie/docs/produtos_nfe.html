Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ExcluirNFe

Parâmetros:
  nfeExcluirRequest nfeExcluirRequest
Solicitação da Exclusão de NF-e.
Retorno nfeExcluirResponse:
Exemplo:
{
    "cChaveNFe": "",
    "nIdImportacao": 0,
    "nIdNFe": 0
}

ImportarCancNFe

Parâmetros:
  nfeCancelarRequest nfeCancelarRequest
Solicitação de Cancelamento da NF-e.
Retorno nfeCancelarResponse:
Exemplo:
{
   "cAppNome": "GeradorNFe",
   "cAppVersao": "1.01.02",
   "cAppId": "NFe01",
   "cChaveNFe": "",
   "cXmlNFeCanc": "",
   "cMd5NFeCanc": ""
}

Parâmetros:

Exemplo:
{
   "cAppNome": "GeradorNFe",
   "cAppVersao": "1.01.02",
   "cAppId": "NFe01",
   "cChaveNFe": "",
   "cXmlNFe": "",
   "cMd5NFe": "",
   "cOperacao": "11",

   "lNaoMovEstoque": true,
   "lNaoGerarTitulo": false,
   "lNaoIncluirCliente": false,
   "lNaoIncluirProduto": true

Lista as NFes importadas.

Tipos Complexos

itens

Itens da Nota Fiscal.

nSequencia integer
Número da Sequencia.
+
Preenchimento obrigatório na Estrutura Itens. Para ItensXml apenas quando for informada a tag lote_validade.

Para os itens da NF identifica qual o item do XML se refere.

Para as parcelas da NF identifica o número da parcela.

Para os lançamentos no Conta Corrente indentifica o lançamento que será gerado.

Permite sequencial de 1 a 999.
nIdProduto integer
ID do produto.
+
Preenchimento opcional.

Caso não informado, fará a pesquisa do produto de acordo com os dados do XML da NF-e.
cCategoria string20
Código da Categoria.
+
Preenchimento opcional.
lNaoGerarTitulo boolean
Não gerar título de contas a pagar ou receber para a NF-e.
+
Preenchimento opcional.

Pode ser:
true - inibe a geração do título de Contas a Pagar ou Receber no financeiro.
false - Gera o ítulo de Contas a Pagar ou Receber no financeiro.

O padrão é true.
lote_validade lote_validadeArray
Informações referentes ao lote e validade do produto.
+
A tag só deve ser informada se o produto possuir controle de lote e se a intenção é informar os lotes "manualmente" por API.
lNaoMovEstoque boolean
Não movimentar o estoque.
+
Preenchimento opcional.

Pode ser:
true - inibe a movimentação do estoque.
false - Gera o movimentação do estoque.

O padrão é true.

Prevalece a informa
codigo_local_estoque integer
Código do local do estoque.
+
Preenchimento opcional.

Assumirá o local padrão de estoque caso não informado.
