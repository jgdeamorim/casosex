Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterResumoProdutos

Obtem o resumo das vendas de produtos.

Parâmetros:
  ObterResumoVendasRequest ObterResumoVendasRequest
Solicitação do resumo de vendas de produtos.
Retorno ObterResumoVendasResponse:
Exemplo:
{
   "dDataInicio":"01/09/2026",
   "dDataFim":"01/09/2026",
   "lApenasResumo": true
}

Tipos Complexos

ObterResumoVendasRequest

dDataInicio string10
Data Inicial de Consulta.
+

Preenchimento opcional.
dDataFim string10
Data final de Consulta.
+

Preenchimento opcional.
lApenasResumo boolean
Exibir apenas o resumo.
+
Quando true será retornado as estruturas:

FaturamentoResumo
pedidoVenda->faturarHoje
propostaVenda->faturarHoje

Quando false retornará todas as estruturas.

Default = true
