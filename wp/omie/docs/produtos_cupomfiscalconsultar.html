Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

CuponsFiscais

Listagem dos cupons fiscais.

Parâmetros:
  cfcListarRequest cfcListarRequest
Solicitação de Listagem dos Cupons Fiscais.
Retorno cfcListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50
}

CuponsItens

Listagem dos itens dos cupons fiscais

Parâmetros:
  cfcItensRequest cfcItensRequest
Solicitação de Listagem dos itens de cupom fiscal.
Retorno cfcItensResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50
}

CuponsPagamentos

Listagem dos pagamentos dos cupons fiscais

Parâmetros:
  cfcPagamentosRequest cfcPagamentosRequest
Solicitação de Listagem dos pagamentos de cupom fiscal.
Retorno cfcPagamentosResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50
}
