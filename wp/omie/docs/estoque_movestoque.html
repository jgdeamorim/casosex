Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ConsultarPrevisao

Parâmetros:
  epPrevisaoRequest epPrevisaoRequest
Previsão de estoque do produto.
Retorno epPrevisaoResponse:
Exemplo:
{
  "nCodProd": 1
}

ListarMovimentos

Parâmetros:
  epListarRequest epListarRequest
Solicitação da listagem movimentos de estoque de entrada/saida de um período.
Retorno epListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20,
  "codigo_local_estoque": 0
}
