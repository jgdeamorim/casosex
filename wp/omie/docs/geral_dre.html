Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarCadastroDRE

Lista as contas do DRE

Parâmetros:
  dreCadastroListRequest dreCadastroListRequest
Lista os DREs cadastrados.
Retorno dreCadastroListResponse: Retorna a lista de Contas do DRE.
Exemplo:
{
  "apenasContasAtivas": "N"
}

Tipos Complexos

dreCadastroListRequest

Lista os DREs cadastrados.

apenasContasAtivas string1
Listar apenas as contas ativas: S ou N.

dreCadastroListResponse

Retorna a lista de Contas do DRE.

totalRegistros integer
total de registros encontrados
dreLista dreListaArray
Cadastro de Contas do DRE.

dreLista

Cadastro de Contas do DRE.

codigoDRE string10
Código da Conta do DRE.
descricaoDRE string40
Descrição da Conta do DRE.
naoExibirDRE string1
Indica se a Conta está marcada para não exibir no DRE.
nivelDRE integer
Nível da Conta da DRE.
sinalDRE string1
Sinal da Conta para o DRE.
totalizaDRE string1
Indica se a Conta do DRE é Totalizadora.

dreListaArray

Este parâmetro é um array do tipo dreLista

Lista de dreLista

omie_fail

code integer
Codigo do erro
description text
Descricao do erro
referer text
Origem do erro
fatal boolean
Indica se eh um erro fatal
