NSU string100
NSU (Número Sequencial Único) identifica uma operação de venda.

Permite que o processo de conciliação de cartões seja realizado de forma mais assertiva, pois identifica os movimentos registrados pelos adquirentes / subadquirentes possibilitando o cruzamento dos dados com os cupons fiscais.

Para vendas realizadas pelo sistema TEF, o NSU é armazenado automaticamente pelo seu PDV.

Para vendas realizadas pelo sistema POS, o NSU pode ser informado manualmente. Verifique com o seu PDV se esse recurso está disponível.

Preenchimento opcional.

caixa

seqCaixa integer
Número sequencial do movimento do caixa.
+
Caso não tenha controle de caixa, enviar um sequencial para cada dia para que seja possível acompanhar os movimentos de caixas por dia.

Preenchimento obrigatório.
seqCupom integer
Número sequencial do cupom fiscal enviado.
+
Não é o número do cupom fiscal, mas sim o número sequencial de venda.

Preenchimento obrigatório.
lCxAberto boolean
Indica se o Caixa está aberto.
+
O padrão é false.

Quando esse campo foi preenchido como true não haverá movimentação de estoque e não será gerado título de contas a receber até que o processo de fechamento do caixa seja executado.

categorias

idCategoria string20
Código da Categoria.
+
(Gerado internamente, não é visualizado na tela)
vCategoria decimal
Valor da categoria
pCategoria decimal
Percentual da categoria

categoriasArray

Este parâmetro é um array do tipo categorias

Lista de categorias

cfFecharCaixaRequest

Efetua a rotina de fechamento do caixa.

emissor emissor
Identificação do Emissor do Cupom Fiscal.
seqCaixa integer
Número sequencial do movimento do caixa.
+
Caso não tenha controle de caixa, enviar um sequencial para cada dia para que seja possível acompanhar os movimentos de caixas por dia.

Preenchimento obrigatório.
fechamento fechamento
Dados do fechamento do caixa.

cfFecharCaixaResponse

Resposta da rotina de fechamento do caixa.

nIdProc integer
Número de identificação do processamento da solicitação.
cCodStatus string4
Código do status de processamento do cupom fiscal.
+
Se retornar 0 indica que o cupom foi processado com sucesso.

Se retornar um valor maior que zero indica o código do erro gerado.
cDesStatus text
Descrição do status de processamento.
+
Caso ocorra erro, retorna a descrição do erro gerado.
listaProcessados listaProcessadosArray
Lista de cupons processados.
