Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

FaturarLoteOS

Parâmetros:
  FaturarLoteOSRequest FaturarLoteOSRequest
Faturar Ordens de serviço em lote a partir da etapa informada.
Retorno FaturarLoteOSResponse:
Exemplo:
{
    "cEtapa":"50"
}

ListarLoteNfse

Parâmetros:
  ListarLoteNfseRequest ListarLoteNfseRequest
Listar Ordens de serviço faturadas a partir do status informado.
Retorno ListarLoteNfseResponse:
Exemplo:
{
   "dDtFat":"01/09/2026",
   "cStatusLote":"001"
}

ListarLotesOS

Parâmetros:
  ListarLotesOSRequest ListarLotesOSRequest
Listar status de faturamento das Ordens de serviço a partir das datas de processamento.
Retorno ListarLotesOSResponse:
Exemplo:
{
   "dDtIncDe":"01/09/2026",
   "dDtIncAte":"01/09/2026"
}

StatusLoteOS

Status do lote faturado a partir do ID.

Parâmetros:
  StatusLoteOsRequest StatusLoteOsRequest
Obtém o status do Lote da Ordem de Serviço
Retorno StatusLoteOsResponse:
Exemplo:
{
    "nIdLoteFat":45223245
}

Tipos Complexos

FaturarLoteOSRequest

cEtapa string2
Etapa da Operação de Venda.
+
Utilize a tag 'codigo' do método 'ListarEtapasFaturamento' da API
/api/v1/produtos/etapafat/
para obter essa informação.

Os valores são fixos, mas as descrições (funções atribuídas a cada coluna pode mudar. A API irá indicar a descrição de cada coluna.

Os valores disponíveis para esse campo podem ser:

'10' - Primeira coluna
'20' - Segunda coluna
'30' - Terceira coluna
'40' - Quarta coluna
'50' - Faturar

FaturarLoteOSResponse

nQtdeFat integer
Qtde de Ordens de Serviço faturadas.
nIdLoteFat integer
Id do Lote de Processamento
cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDesStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
