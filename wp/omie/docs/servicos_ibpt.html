Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarProdutosIBPT

Lista os produtos da Tabela do IBPT.

Parâmetros:
  ibptListarProdRequest ibptListarProdRequest
Solicitação da Tabela IBPT da Empresa.
Retorno ibptListarProdResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}

ListarServicosIBPT

Parâmetros:
  ibptListarServRequest ibptListarServRequest
Solicitação da Tabela IBPT da Empresa.
Retorno ibptListarServResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}
