+

ItensExclusaoArray

Este parâmetro é um array do tipo ItensExclusao

Lista de ItensExclusao

cabecalho

nCodCtr integer
Código do contrato de serviços.
+
(Gerado internamente, não é visualizado na tela)
cCodIntCtr string20
Código de integração do contrato de serviços.
+
(Utilizado em contratos criados via API, não é visualizado na tela)
nCodCli integer
Código do cliente a que se refere o contrato de serviços.
+
(Gerado internamente, não é visualizado na tela)
cNumCtr string60
Número do contrato de serviços.
+
(Informado pelo usuário / visualizado na tela)
cCodSit string2
Código da situação do contrato de serviços.
+
Pode ser:
00 - Em Elaboração
10 - Ativo
90 - Suspenso
99 - Cancelado
dVigInicial string10
Data da vigência inicial do contrato de serviços.
dVigFinal string10
Data de vigência final do contrato de serviços.
nDiaFat integer
Dia de faturamento.
nValTotMes decimal
Valor total mensal do contrato de serviços.
+
(Calculado automaticamente)
cTipoFat string2
Tipo de Faturamento do Contrato.
+
Pode ser:
01 - Todo Mês (mensal)
02 - A cada 2 meses (bimestral)
03 - A cada 3 meses (trimestral)
06 - A cada 6 meses (semestral)
12 - A cada 12 meses (anual)
