Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarTarefa

Parâmetros:
  AlterarTarefaRequest AlterarTarefaRequest
Solicitação de alteração de uma tarefa.
Retorno AlterarTarefaResponse:
Exemplo:
{
   "nCodTarefa": 0,
   "cCodIntTarefa": "",
   "cDescricao": "",
   "dData": "01/09/2026",
   "hHora": "12:30",
   "cImportante": "N",
   "cUrgente": "N",
   "cSituacao": "pendente",
   "nCodAtividade": 0,
   "nCodNotif": 0,
   "nCodUserAtb": 0
}

ConsultarTarefa

Parâmetros:
  ConsultarTarefaRequest ConsultarTarefaRequest
Solicitação da consulta de uma tarefa.
Retorno ConsultarTarefaResponse:
Exemplo:
{
    "nCodTarefa": 0,
    "cCodIntTarefa": ""
}

ExcluirTarefa

Parâmetros:
  ExcluirTarefaRequest ExcluirTarefaRequest
Solicitação de exclusão de uma tarefa.
Retorno ExcluirTarefaResponse:
Exemplo:
{
    "nCodTarefa": 0,
    "cCodIntTarefa": ""
}

IncluirTarefa

Parâmetros:
  IncluirTarefaRequest IncluirTarefaRequest
Solicitação de cadastro de tarefa.
Retorno IncluirTarefaResponse:
Exemplo:
{
   "cCodIntTarefa": "",
   "cOrigem": "",
   "cDescricao": "",
   "dData": "01/09/2026",
   "hHora": "12:30",
   "cImportante": "N",
   "cUrgente": "N",
   "cSituacao": "pendente",
   "nCodAtividade": 0,
   "nCodNotif": 0,
   "nCodUserAtb": 0,
   "nCodDoc": 0
}

ListarTarefas

Parâmetros:
  ListarTarefasRequest ListarTarefasRequest
Solicitação da listagem de tarefas cadastradas.
Retorno ListarTarefasResponse:
Exemplo:
{
    "nPagina": 1,
    "nRegPorPagina": 100,
    "cOrigem": "",
    "cImportante": "",
    "cUrgente": "",
    "cSituacao": "",
    "dDataInicial": "",
    "dDataFinal": ""
}

ObterCalendarioTarefas

Parâmetros:
  ObterCalendarioTarefasRequest ObterCalendarioTarefasRequest
Solicitação para obter informações do calendário das tarefas.
Retorno ObterCalendarioTarefasResponse:
Exemplo:
{
    "dDataInicial": "",
    "dDataFinal": "",
    "cOrigem": ""
}

ObterResumoTarefas

Parâmetros:
  ObterResumoTarefasRequest ObterResumoTarefasRequest
Solicitação para obter o resumo das tarefas.
Retorno ObterResumoTarefasResponse:
Exemplo:
{
    "cApenasResumo": "S"
}

ObterTotalTarefas

Parâmetros:
  ObterTotalTarefasRequest ObterTotalTarefasRequest
Solicitação para obter o número de tarefas por documento e origem.
Retorno ObterTotalTarefasResponse:
Exemplo:
{
    "cOrigem": "",
    "nCodDoc": 0
}
