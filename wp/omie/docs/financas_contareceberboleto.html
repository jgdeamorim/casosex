Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

CancelarBoleto

Cancela o Boleto.

Parâmetros:
  boletoCancelarRequest boletoCancelarRequest
Cancela o Boleto.
+
ATENÇÃO: Os boletos gerados e já enviados ao banco estão sujeitos a tarifação (de emissão, cancelamento ou de alteração da data de vencimento do boleto).
Retorno boletoCancelarResponse:
Exemplo:
{
   "nCodTitulo": 0,
   "cCodIntTitulo": ""
}

GerarBoleto

Gera um Boleto referente a um Contas a Receber.

Parâmetros:
  boletoGerarRequest boletoGerarRequest
Gera um Boleto a partir de um Contas a Receber.
+
ATENÇÃO: Os boletos gerados e já enviados ao banco estão sujeitos a tarifação (de emissão, cancelamento ou de alteração da data de vencimento do boleto).
Retorno boletoGerarResponse:
Exemplo:
{
   "nCodTitulo": 0,
   "cCodIntTitulo": ""
}

ObterBoleto

Disponibiliza o link de Download do Boleto.

Parâmetros:
  boletoObterRequest boletoObterRequest
Solicitação do link do boleto de um título.
+
ATENÇÃO: Os boletos gerados e já enviados ao banco estão sujeitos a tarifação (de emissão, cancelamento ou de alteração da data de vencimento do boleto).
Retorno boletoObterResponse:
Exemplo:
{
   "nCodTitulo": 0,
   "cCodIntTitulo": ""
}

ProrrogarBoleto

Prorroga o vencimento do Boleto.

Parâmetros:
  boletoProrrogarRequest boletoProrrogarRequest
Prorroga o vencimento de um Boleto.
+
ATENÇÃO: Os boletos gerados e já enviados ao banco estão sujeitos a tarifação (de emissão, cancelamento ou de alteração da data de vencimento do boleto).
Retorno boletoProrrogarResponse:
Exemplo:
{
   "nCodTitulo": 0,
   "cCodIntTitulo": "",
   "dDtVenc":"01/09/2026"
}
