Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarVendedor

Altera os dados de um vendedor

Parâmetros:
  vendAlterarRequest vendAlterarRequest
Solicitação de Alteração de um vendedor
Retorno vendAlterarResponse:
Exemplo:
{
   "codigo": 0,
   "codInt": "123",
   "nome": "",
   "inativo": "N",
   "email": "teste@minhaempresa.com.br",
   "fatura_pedido": "S",
   "visualiza_pedido": "N",
   "comissao": 10.00
}

ConsultarVendedor

Consulta os dados de um vendedor

Parâmetros:
  vendConsultarRequest vendConsultarRequest
Solicitação de Consulta de um Vendedor
Retorno vendConsultarResponse: Reposta da consulta de Vendedores
Exemplo:
{
   "codigo": 0,
   "codInt": "123"
}

ExcluirVendedor

Exclui um vendedor

Parâmetros:
  vendExcluirRequest vendExcluirRequest
Solicitação de Exclusão de um fornecedor.
Retorno vendExcluirResponse:
Exemplo:
{
   "codigo": 0,
   "codInt": "123"
}

IncluirVendedor

Inclui um vendedor

Parâmetros:
  vendincluirRequest vendincluirRequest
Solicitação de Inclusão de um vendedor
Retorno vendIncluirResponse:
Exemplo:
{
   "codInt": "123",
   "nome": "",
   "inativo": "N",
   "email": "teste@minhaempresa.com.br",
   "fatura_pedido": "S",
   "visualiza_pedido": "N",
   "comissao": 10.00
}

ListarVendedores

Listagem de Vendedores

Parâmetros:
  vendListarRequest vendListarRequest
Solicitação de Listagem de Vendedores
Retorno vendListarResponse: Resposta da listagem de Vendedores
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 100,
  "apenas_importado_api": "N"
}

UpsertVendedor

Inclui / Altera um vendedor

Parâmetros:
  vendUpsertRequest vendUpsertRequest
Solicitação de Inclusão/Alteração de um vendedor
Retorno vendUpsertResponse:
Exemplo:
{
   "codigo": 0,
   "codInt": "123",
   "nome": "",
   "inativo": "N",
   "email": "teste@minhaempresa.com.br",
   "fatura_pedido": "S",
   "visualiza_pedido": "N",
   "comissao": 10.00
}
