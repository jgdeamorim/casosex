}

StatusDevolucaoVenda

Parâmetros:
  StatusDevolucaoVendaRequest StatusDevolucaoVendaRequest
Solicitação de consulta do Status da Devolução do Pedido de Venda.
Retorno StatusDevolucaoVendaResponse:
Exemplo:
{
   "nCodDevol": 0
}

Tipos Complexos

FaturarDevolucaoVendaResponse

nCodDevol integer
Id da Devolução do Pedido de Venda.
cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDescStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
