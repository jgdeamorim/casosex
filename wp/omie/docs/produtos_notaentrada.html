Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarNotaEnt

Alterar nota de entrada

Parâmetros:
  neAlterarRequest neAlterarRequest
Solicitação de alteração da nota de entrada
Retorno neAlterarResponse:
Exemplo:
{
  "cabec": {
    "cCodIntNotaEnt": "NE1788303486",
    "dPrevisao": "01/09/2026",
    "nCodCli": 2370765
  },
  "infAdic": {
      "cCodCateg": "2.01.03"
   },
  "produtos": [
    {
      "cCodItInt": "IT1788303486",
      "nCodProd": 426738565,
      "nQtde": 1,
      "nValUnit": 100,
      "cCFOP": "1.152"
    }
  ]
}

ConsultarNotaEnt

Consultar nota de entrada

Parâmetros:
  neConsultarRequest neConsultarRequest
Solicitação de consulta da nota de entrada
Retorno neConsultarResponse:
Exemplo:
{
   "nCodNotaEnt" : 0,
   "cCodIntNotaEnt" : ""
}

Código de Integração da Nota de Entrada

Preenchimento obrigatório na inclusão e na alteração quando nCodNotaEnt não for informado.

Preencha esse campo com o código da nota de entrada no aplicativo que você está integrando com o Omie. A função dele é servir como uma mapa de relacionamento entre as aplicações. Ao realizar uma consulta/listagem de notas de entrada você conseguirá ver a relação entre o id da nota de entrada gerado no Omie e o código de pedido existente em sua aplicação.

para obter essa informação.
