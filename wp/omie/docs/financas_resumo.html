Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterDetalhesLancamento

Parâmetros:
  ObterDetalhesLancamentoRequest ObterDetalhesLancamentoRequest
Solicitação dos detalhes de um lançamento em aberto.
Retorno ObterDetalhesLancamentoResponse:
Exemplo:
{
    "nIdTitulo": 0
}

ObterListaEmAberto

Parâmetros:
  ObterListaEmAbertoRequest ObterListaEmAbertoRequest
Solicitação da listagem de lançamentos em aberto.
Retorno ObterListaEmAbertoResponse:
Exemplo:
{
   "dDia": "01/09/2026",
   "cTipo": "P",
   "nPagina": 1,
   "nRegPorPagina": 50
}

ObterListaFinancas

Parâmetros:
  ObterListaFinancasRequest ObterListaFinancasRequest
Solicitação da listagem de lançamentos.
Retorno ObterListaFinancasResponse:
Exemplo:
{
   "dDia": "01/09/2026",
   "cCodCateg": "1.01.01",
   "cTipo": "R"
}

ObterResumoFinancas

Parâmetros:
  ObterResumoFinRequest ObterResumoFinRequest
Solicitação do resumo de finanças
Retorno ObterResumoFinResponse:
Exemplo:
{
  "dDia": "01/09/2026",
  "lApenasResumo": true
}

ObterResumoFinRequest

dDia string10
Informe aqui a data de registro para listar os lançamentos.
+
Default data atual.

Preenchimento opcional.
lApenasResumo boolean
Exibir apenas o resumo.
+
Quando true será retornado as estruturas:

contaCorrente
contaPagar
contaReceber

Quando false retornará todas as estruturas.

Default = true
lExibirCategoria boolean
Exibir os valores dos lançamentos por categoria.
+
Quando true será retornado as estruturas:

contaPagarCategoria
contaReceberCategoria

Default = true
