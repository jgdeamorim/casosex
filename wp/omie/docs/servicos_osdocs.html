Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterDemonst

Parâmetros:
  ObterDemonstRequest ObterDemonstRequest
Solicita as informações de um Demonstrativo.
Retorno ObterDemonstResponse:
Exemplo:
{
   "nIdNf": 0
}

Tipos Complexos

ObterDemonstRequest

nIdNf integer
ID do documento fiscal.
+
Essa informação pode ser obtida pela API:
/api/v1/mobile/faturamento/
Retornado na tag 'nIdDoc'

Preenchimento obrigatório.

ObterDemonstResponse

cNumOs string15
Número da Ordem de Serviço.
cPdfDemonst text
Link para obter o PDF do Demonstrativo.
+
cLinkPortal text
Link para acessar os documentos no portal Omie.
cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDesStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
