Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarEtapasPedido

Lista as etapas do Pedido de Venda de Produtos.

Parâmetros:
  pEtapaListarRequest pEtapaListarRequest
Solicitação de listagem de mudanças de etapa do pedido de vendas.
Retorno pEtapaListarResponse: Resposta da listagem de Status do Pedido de Vendas.
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20
}
