Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AssociarCodIntPedidoVenda

Parâmetros:
  pvpAssociarCodIntRequest pvpAssociarCodIntRequest
Solicitação de alteração do código de integração do Pedido de Venda de Produto.
Retorno pvpAssociarCodIntResponse:
Exemplo:
{
  "cCodIntPed": "",
  "nCodPed": 0
}

CancelarPedidoVenda

Cancela um pedido de venda de produto.

Parâmetros:
  pvpCancelarRequest pvpCancelarRequest
Solicitação de cancelamento da Pedido de Venda de Produto.
Retorno pvpCancelarResponse:
Exemplo:
{
  "cCodIntPed": "",
  "nCodPed": 0
}

DuplicarPedidoVenda

Duplica um pedido de venda de produto.

Parâmetros:
  pvpDuplicarRequest pvpDuplicarRequest
Solicitação de cópia do Pedido de Venda de Produto.
Retorno pvpDuplicarResponse:
Exemplo:
{
  "cCodIntPed": "",
  "nCodPed": 0
}

FaturarPedidoVenda

Fatura um pedido de venda de produto.

Parâmetros:
  pvpFaturarRequest pvpFaturarRequest
Solicitação de faturamento da Pedido de Venda de Produto.
Retorno pvpFaturarResponse:
Exemplo:
{
  "cCodIntPed": "",
  "nCodPed": 0
}

ObterPedidosVenda

Retorna a lista de pedidos de venda a serem faturados.

Parâmetros:
  pvpObterRequest pvpObterRequest
Solicitação da obtenção de Pedidos de Venda em etapa a Faturar
Retorno pvpObterResponse:
Exemplo:
{
  "cEtapa":"50"
}

ValidarPedidoVenda

Valida um pedido de venda de produto para faturamento.

Parâmetros:
  pvpValidarRequest pvpValidarRequest
Solicitação de validação da Pedido de Venda de Produto.
Retorno pvpValidarResponse:
Exemplo:
{
  "cCodIntPed": "",
  "nCodPed": 0
}
