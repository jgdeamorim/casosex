Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

CancelarCupom

Cancela um cupom Fiscal

Parâmetros:
  cfCancelarRequest cfCancelarRequest
Solicitação de cancelamento do Cupom Fiscal.
Retorno cfCancelarResponse:
Exemplo:
{
  "nIdCupom": 0
}

Parâmetros:

Solicitação de cancelamento de NFC-e.
Retorno cfCancelarNfceResponse:
Exemplo:
{
   "nCodigoPDV": 0,
   "nNumeroCaixa": 0,
   "cDataEmissao": "",
   "IdenticacaoNFCE": {
      "nNumeroNFCE": 0,
      "nSerieNFCE": 0,
      "nChaveNFCE": ""
   },
   "DadosCancNFCE": {
      "nProtCancNFCE": 0,
      "nChaveCancNFCE": "",
      "cXmlCancNFCE": "",
      "cDataCancelamento": "",
      "cHoraCancelamento": ""
   }
}

INU - Cupom Inutilizado.
