Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarOrdemProducao

Parâmetros:
  copAlterarRequest copAlterarRequest
Solicitação de alteração da ordem de produção.
Retorno copAlterarResponse:
Exemplo:
{
     "identificacao": 
     {
         "cCodIntOP": "OP0001",
         "dDtPrevisao": "01/09/2026",
         "nCodProduto": 0,
         "nQtde": 3
      }
}

ConcluirOrdemProducao

Parâmetros:
  copConcluirRequest copConcluirRequest
Solicitação de conclusão da ordem de produção.
Retorno copConcluirResponse:
Exemplo:
{ 
   "cCodIntOP": "",
   "nCodOP": 0,
   "dDtConclusao": "01/09/2026",
   "nQtdeProduzida": 3,
   "cObsConclusao": ""    
}

ConsultarOrdemProducao

Parâmetros:
  copConsultarRequest copConsultarRequest
Solicitação da consulta da ordem de produção.
Retorno copConsultarResponse:
Exemplo:
{ 
   "cCodIntOP": "",
   "nCodOP": 0
}

ExcluirOrdemProducao

Parâmetros:
  copExcluirRequest copExcluirRequest
Solicitação de exclusão da ordem de produção.
Retorno copExcluirResponse:
Exemplo:
{ 
   "cCodIntOP": "",
   "nCodOP": 0
}

IncluirOrdemProducao

Parâmetros:
  copIncluirRequest copIncluirRequest
Solicitação de Inclusão da ordem de produção.
Retorno copIncluirResponse:
Exemplo:
{
     "identificacao": 
     {
         "cCodIntOP": "OP0001",
         "dDtPrevisao": "01/09/2026",
         "nCodProduto": 0,
         "nQtde": 3
      }
}

ListarOrdemProducao

Parâmetros:
  copListarRequest copListarRequest
Solicitação da listagem de ordens de produção.
Retorno copListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20,
   "dDtConclusaoDe":"01/09/2026",
   "dDtConclusaoAte":"01/09/2026"
}

ReverterOrdemProducao

Parâmetros:
  copReverterRequest copReverterRequest
Solicitação de reversão da conclusão da ordem de produção.
Retorno copReverterResponse:
Exemplo:
{ 
   "cCodIntOP": "",
   "nCodOP": 0
}

UpsertOrdemProducao

Parâmetros:
  copUpsertRequest copUpsertRequest
Solicitação de upsert de ordem de produção.
Retorno copUpsertResponse:

{
     "identificacao":

         "cCodIntOP": "OP0001",
