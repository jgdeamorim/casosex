Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterListaOp

Lista de Oportunidades.

Parâmetros:
  ObterListaOpRequest ObterListaOpRequest
Solicitação da listagem de Oportunidades.
Retorno ObterListaOpResponse:
Exemplo:
{
   "cMesAno": "04/2022",
   "cTemperatura": "em-processo"
}

ObterResumoOp

Resumo das oportunidades.

Parâmetros:
  resumooportunidades_obterresumoop_request resumooportunidades_obterresumoop_request
ObterResumoOp Request
Retorno resumooportunidades_obterresumoop_response: ObterResumoOp Response
Exemplo:
{
   "nIdVendedor":0,
   "nIdParceiro":0,
   "cMesAno":"02/2022",
   "lApenasResumo": true
}

Tipos Complexos

ObterListaOpRequest

cMesAno text
Mes e ano. (MM/AAAA).
+
Default mês atual.

Preenchimento opcional.
cTemperatura text
Informe a temperatura da Oportundiade.
+
Pode ser:
em-processo
boas-chances
comprometido
conquistado

Preenchimento obrigatório.

ObterResumoOp Request

nIdVendedor integer
Código do usuário / vendedor.
nIdParceiro integer
Código do parceiro ou equipe.
cMesAno text
Mes e ano. (MM/AAAA).
lApenasResumo boolean
Exibir apenas o resumo.
+
Quando true será retornado as estruturas:
funilOportunidades->mesAtual
saudePipeline
Quando false retornará todas as estruturas.
Default = true
