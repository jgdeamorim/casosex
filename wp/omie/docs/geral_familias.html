Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarFamilia

Altera uma familia de produto

Parâmetros:
  famCadastro famCadastro
Cadastro de Familias de Produtos
Retorno famStatus: Status da Familia de Produtos
Exemplo:
{
   "codigo" : 0,
   "codInt" : "FA1788306294", 
   "codFamilia" : "", 
   "nomeFamilia" : "",
   "inativo" : "N"
}

ConsultarFamilia

Consulta uma familia de produto

Parâmetros:
  famConsultarRequest famConsultarRequest
Solicitação de Consulta de uma Familia de Produtos
Retorno famConsultarResponse: Resposta do consulta de Familias de Produtos
Exemplo:
{
   "codigo" : 0,
   "codInt" : "" 
}

ExcluirFamilia

Exclui uma familia de produto

Parâmetros:
  famChave famChave
chave de pesquisa do Cadastro de Familias de produtos
Retorno famStatus: Status da Familia de Produtos
Exemplo:
{
   "codigo" : 0,
   "codInt" : ""
}

IncluirFamilia

Inclui uma familia de produto

Parâmetros:
  famCadastro famCadastro
Cadastro de Familias de Produtos
Retorno famStatus: Status da Familia de Produtos
Exemplo:
{
   "codInt" : "FA1788306294",  
   "codFamilia" : "", 
   "nomeFamilia" : "",
   "inativo" : "N"
}

PesquisarFamilias

Listagem de familias cadastradas

Parâmetros:
  famListarRequest famListarRequest
Solicitação de Listagem de Familias de Produtos
Retorno famListarResponse: Resposta da listagem de Familias de Produtos
Exemplo:
{
   "pagina" : 1,
   "registros_por_pagina" : 50
}
