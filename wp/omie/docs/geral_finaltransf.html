ConsultarFinalTransf

Parâmetros:
  final_transf_list_request_consulta final_transf_list_request_consulta
Requisição para consulta de finalidades de transferências cadastradas
Retorno cadastros:
Exemplo:
{
  "banco": "104"
,
  "codigo": "01"
}

ListarFinalTransf

Parâmetros:
  final_transf_list_request final_transf_list_request
Requisição para listagem as finalidades de transferências cadastradas
Retorno final_transf_list_response:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 50
}
