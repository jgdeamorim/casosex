Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ConsultarBanco

Parâmetros:
  fin_bancos_cadastro_chave fin_bancos_cadastro_chave
Chave para pesquisa do cadastro de Bancos / Instituíções Financeiras.
Retorno fin_banco_cadastro:
Exemplo:
{
   "codigo": ""
}

ListarBancos

Exibe uma lista com os banco cadastrados.

Parâmetros:
  fin_bancos_list_request fin_bancos_list_request
Lista os bancos / instituíções financeiras cadastrados.
Retorno fin_bancos_list_response: Lista de produtos encontrados no omie.
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 100
}
