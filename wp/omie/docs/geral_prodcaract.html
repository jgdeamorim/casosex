Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCaractProduto

Parâmetros:
  prcAlterarCaractRequest prcAlterarCaractRequest
Altera uma característica para um produto.
Retorno prcAlterarCaractResponse:
Exemplo:
{
   "nCodProd": 0,
   "cCodIntProd": "",
   "nCodCaract": 0,
   "cCodIntCaract": "",
   "cConteudo": "",
   "cExibirItemNF": "S",
   "cExibirItemPedido": "S",
   "cExibirOrdemProd": "S"
}

ConsultarCaractProduto

Parâmetros:
  prcConsultarCaractRequest prcConsultarCaractRequest
Consulta uma característica de um produto.
Retorno prcConsultarCaractResponse:
Exemplo:
{
  "nCodProd": 0,
  "cCodIntProd": "",
  "nCodCaract": 0,
  "cCodIntCaract": ""
}

ExcluirCaractProduto

Parâmetros:
  prcExcluirCaractRequest prcExcluirCaractRequest
Exclui uma característica de um produto.
Retorno prcExcluirCaractResponse:
Exemplo:
{
   "nCodProd": 0,
   "cCodIntProd": "",
   "nCodCaract": 0,
   "cCodIntCaract": ""

ListarCaractProduto

Parâmetros:
  prcListarCaractRequest prcListarCaractRequest
Listagem de características de um produto.
Retorno prcListarCaractResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50,
  "nCodProd": 0
}
