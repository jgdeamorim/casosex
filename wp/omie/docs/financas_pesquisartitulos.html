Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterURLBoleto

DEPRECATED

Parâmetros:
  ltLinkBoletoRequest ltLinkBoletoRequest
Solicitação do link do boleto de um título.
Retorno ltLinkBoletoResponse:
Exemplo:
{
  "nCodTitulo": 0,
  "cCodIntTitulo": ""
}

PesquisarExcluidos

DEPRECATED

Parâmetros:
  ltListarExcluidosRequest ltListarExcluidosRequest
Solicitação da listagem de contas a pagar e receber excluídas. 
Retorno ltListarExcluidosResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20
}

PesquisarLancamentos

Parâmetros:
  ltPesquisarRequest ltPesquisarRequest
Solicitação de Listagem de Contas a Receber
Retorno ltPesquisarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20
}
