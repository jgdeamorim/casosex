Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterEstoqueProduto

Parâmetros:
  ObterEstoqueProdRequest ObterEstoqueProdRequest
Solicitação da posição de estoque do produto.
Retorno ObterEstoqueProdResponse:
Exemplo:
{
  "cEAN": "",
  "nIdProduto": 0,
  "cCodigo": "",
  "xCodigo": "",
  "dDia": "01/09/2026"
}
