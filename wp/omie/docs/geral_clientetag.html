Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ExcluirTags

Remove tags associadas a um cliente.

Parâmetros:
  cTagExcluirRequest cTagExcluirRequest
Solicitação de exclusão de tags de um cliente.
Retorno cTagExcluirResponse:
Exemplo:
{
  "nCodCliente": 0,
  "cCodIntCliente": "",
  "tags": [ { "tag": "Grupo A" }, { "tag": "Grupo B" } ]
}

ExcluirTodas

Remove todas as tags associadas a um cliente.

Parâmetros:
  cTagExcluirTodasRequest cTagExcluirTodasRequest
Solicitação de exclusão de todas as tags de um cliente.
Retorno cTagExcluirTodasResponse:
Exemplo:
{
  "nCodCliente": 0,
  "cCodIntCliente": ""
}

IncluirTags

Associa tags a um cliente.

Parâmetros:
  cTagIncluirRequest cTagIncluirRequest
Solicitação de inclusão de tags de um cliente.
Retorno cTagIncluirResponse:
Exemplo:
{
  "nCodCliente": 0,
  "cCodIntCliente": "",
  "tags": [ { "tag": "Grupo A" }, { "tag": "Grupo B" } ]
}

ListarTags

Lista as tags de um determinado cliente.

Parâmetros:
  cTagListarRequest cTagListarRequest
Solicitação da listagem de tags de um cliente.
Retorno cTagListarResponse:
Exemplo:
{
  "nCodCliente": 0,
  "cCodIntCliente": ""
}
