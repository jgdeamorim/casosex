Tipos Complexos

caracteristicas

cTemValidade string1
Indica se a Tabela de Preço possui Validade (S/N).
dDtInicial string10
Data Inicial da Validade da Tabela de Preço.
+
No formato dd/mm/aaaa.
dDtFinal string10
Data Final de Validade Tabela de Preço.
+
No formato dd/mm/aaaa.
cTemDesconto string1
Indica se a Tabela de Preço possui Desconto Sugerido ou Máximo (S/N).
nDescSugerido decimal
Percentual de Desconto Sugerido.
nPercDescMax decimal
Percentual de Desconto Máximo Permitido.
cArredPreco string1
Indica se deve Arredondar o preço do produto (S/N).

clientes

Dados dos filtros do cliente.

cTodosClientes string1
Considerar todos os clientes nesta tabela de preços? (S/N)
+
O padrão é "S".
Quando informar "S", todos os demais campos deste grupo serão desconsiderados.
Caso informe "N", pelo menos 1 dos campos deste grupo deverá ser informado.
nCodTag integer
Considerar apenas os clientes de uma determinada Tag.
+
Será ignorado caso o campo "cTodosClientes" estiver preenhido com "S".
cTag text
Descrição da tag do cliente informada no campo nCodTag.
+
O conteúdo deste campo é apenas informativo e não tem efeito na inclusão.
Na inclusão utilize a tag "nCodTag".
cUF string2
Considerar apenas os clientes do Estado.
+
Será ignorado caso o campo "cTodosClientes" estiver preenhido com "S".
