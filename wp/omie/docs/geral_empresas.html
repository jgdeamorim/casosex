Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ConsultarEmpresa

Realiza a consulta de um registro especifico

Parâmetros:
  empresas_consultar empresas_consultar
Consulta um código no cadastro de Empresas
Retorno empresas_cadastro: Cadastro de Empresas
Exemplo:
{
   "codigo_empresa": 0
}

ListarEmpresas

Lista as empresas cadastradas no Omie.

Parâmetros:
  empresas_list_request empresas_list_request
Lista as empresas cadastradas
Retorno empresas_list_response: Lista de empresas cadastradas no omie.
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 100,
  "apenas_importado_api": "N"
}
