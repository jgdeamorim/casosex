Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

CancelarNotaEnt

Cancelar nota de entrada

Parâmetros:
  nefatCancelarRequest nefatCancelarRequest
Solicitação de cancelamento de nota de entrada
Retorno nefatCancelarResponse: Resposta de cancelamento da nota de entrada
Exemplo:
{
   "nCodNotaEnt" : 0,
   "cCodIntNotaEnt" : ""
}

ConcluirNotaEnt

Concluir nota de entrada

Parâmetros:
  nefatConcluirRequest nefatConcluirRequest
Solicitação de conclusão de nota de entrada
Retorno nefatConcluirResponse:
Exemplo:
{
   "nCodNotaEnt" : 0,
   "cCodIntNotaEnt" : ""
}

ConferirNotaEnt

Conferir nota de entrada

Parâmetros:
  nefatConferirRequest nefatConferirRequest
Solicitação de conferência de nota de entrada
Retorno nefatConferirResponse:
Exemplo:
{
   "nCodNotaEnt" : 0,
   "cCodIntNotaEnt" : ""
}

DuplicarNotaEnt

Duplicar nota de entrada

Parâmetros:
  nefatDuplicarRequest nefatDuplicarRequest
Solicitação de duplicação de nota de entrada
Retorno nefatDuplicarResponse:
Exemplo:
{
   "nCodNotaEnt" : 0,
   "cCodIntNotaEnt" : ""
}

Tipos Complexos

nefatCancelarRequest

nCodNotaEnt integer
ID da nota de entrada.
+
Preenchimento automático na inclusão - Informe esse campo somente para pesquisa.

Esse campo não é exibido na tela.
É uma informação interna, utilizada apenas nas APIs.
cCodIntNotaEnt string20
Código de integração da nota de entrada.
+
Preenchimento Obrigatório na inclusão/alteração.
Preenchimento Opcional na Consulta/Pesquisa.

Preencha esse campo com o código da nota de entrada no aplicativo que você está integrando com o Omie. A função dele é servir como uma mapa de relacionamento entre as aplicações. Ao realizar uma consulta/listagem de notas de entrada você conseguirá ver a relação entre o id da nota de entrada gerado no Omie e o código de nota de entrada existente em sua aplicação.
