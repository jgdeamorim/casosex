ListarExtrato

Listagem do Extrato

Parâmetros:
  eccListarExtratoRequest eccListarExtratoRequest
Solicitação de consulta do Extrato de Conta Corrente.
Retorno eccListarExtratoResponse:
Exemplo:
{
   "nCodCC": 0,
   "cCodIntCC": "",
   "dPeriodoInicial": "",
   "dPeriodoFinal": ""
}
