Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarMovimentoEstoque

Parâmetros:
  ListarMovEstoqueRequest ListarMovEstoqueRequest
Solicitação da listagem de movimentação do estoque.
Retorno ListarMovEstoqueResponse:
Exemplo:
{
   "nPagina": 1,
   "nRegPorPagina": 50,
   "codigo_local_estoque": 0,
   "idProd": 0,
   "dDtInicial": "01/09/2026",
   "dDtFinal": "01/09/2026",
   "lista_local_estoque": ""
}

ListarPosEstoque

Parâmetros:
  ListarEstPosRequest ListarEstPosRequest
Solicitação da listagem da posição do estoque.
Retorno ListarEstPosResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50,
  "dDataPosicao": "01/09/2026",
  "cExibeTodos": "N",
  "codigo_local_estoque": 0
}

ListarSaldoPendente

Lista o saldo pendente de estoque.

Parâmetros:
  estoque_listar_pendente_request estoque_listar_pendente_request
Solicitação de listagem de saldo pendente de estoque.
Retorno estoque_listar_pendente_response:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 50,
  "codigo_local_estoque": 0,
  "id_prod": 0,
  "tipo": "TODOS"
}

MovimentoEstoque

Consulta do Movimento de Estoque

Parâmetros:
  estoqueMovimentoRequest estoqueMovimentoRequest
Consulta Movimento de Estoque de um Produto
Retorno estoqueMovimentoResponse:
Exemplo:
{
  "codigo_local_estoque": 0,
  "id_prod": 0,
  "cod_int": "",
  "dataInicial": "01/09/2026",
  "dataFinal": "01/09/2026"
}

PosicaoEstoque

Parâmetros:
  estoque_mov_consulta_cadastro estoque_mov_consulta_cadastro
Registro de Consulta de Estoque
Retorno estoque_mov_consulta_cadastro_resposta: Status de Resposta da Consulta de Estoque
Exemplo:
{
  "codigo_local_estoque": 0,
  "id_prod": 0,
  "cod_int": "",
  "data": "01/09/2026"
}

+
Padrão: "N"

+
Preenchimento opcional.

cTipoItem string2
Código do Tipo do Item.
+
Informação localizada na aba Recomendações Fiscais do cadastro do produto.

Pode ser:

00 - Mercadoria para Revenda
01 - Matéria Prima
02 - Embalagem
03 - Produto em Processo
04 - Produto Acabado
05 - Subproduto
06 - Produto Intermediário
07 - Material de Uso e Consumo
08 - Ativo Imobilizado
09 - Serviços
10 - Outros Insumos
99 - Outras
KT - Kit
