Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarComponentesKit

Inclui/Altera/Exclui os componentes do KIT.

Parâmetros:
  AlterarCompKitRequest AlterarCompKitRequest
Inclui/Altera/Exclui os componentes do KIT.
Retorno AlterarCompKitResponse:
Exemplo:
{
   "codigo_produto": 0,
   "componentes_kit": [
      {
         "acao_componente": "I",
         "codigo_componente": 0,
         "codigo_produto_componente": 0,
         "valor_unitario_componente": 1.99,
         "quantidade_componente": 1,
         "codigo_local_estoque": 0
      }
   ]
}

Tipos Complexos

AlterarCompKitRequest

Inclui/Altera/Exclui os componentes do KIT.

codigo_produto integer
ID do produto que irá receber os componentes do KIT.
+
(utilizado apenas na integração via API, não é exibido na tela).
O conteúdo desse campo é o código interno gerado pelo Omie ao cadastrar o produto.

Para incluir componentes do KIT, o Tipo do Produto deve ser: "KT - Kit"

Preenchimento obrigatório.
componentes_kit componentes_kitArray
Lista de Componentes do KIT.

AlterarCompKitResponse

cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDesStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
codigo_produto integer
ID do produto que irá receber os componentes do KIT.
+
(utilizado apenas na integração via API, não é exibido na tela).
O conteúdo desse campo é o código interno gerado pelo Omie ao cadastrar o produto.

Para incluir componentes do KIT, o Tipo do Produto deve ser: "KT - Kit"

Preenchimento obrigatório.
componentes_kit componentes_kitArray
Lista de Componentes do KIT.

componentes_kit

Lista de Componentes do KIT.

acao_componente string1
Indica se irá Incluir/Alterar ou Excluir o componente.
+
Pode ser:

"A" - Alterar o componente.
"E" - Excluir o componente
"I" - Incluir o componente
codigo_componente integer
Identificação do componente do KIT, deve ser utilizado para Alterar e Excluir o componente.
+
Não deve ser informado na inclusão.

Esse código não aparece na tela do Omie.

Preenchimento obrigatório na Alteração e Exclusão.
codigo_produto_componente integer
ID do produto que deseja Incluir ou Alterar no KIT.
+
(utilizado apenas na integração via API, não é exibido na tela).
O conteúdo desse campo é o código interno gerado pelo Omie ao cadastrar o produto.

Preenchimento obrigatório na Inclusão.
quantidade_componente decimal
Quantidade do componente.
+
Preenchimento obrigatório na inclusão.
valor_unitario_componente decimal
Valor unitário do componente.
+
Preenchimento obrigatório na inclusão.
codigo_local_estoque integer
ID do local de estoque
+
Caso não seja informado será atribuido o local de estoque padrão.

Utilize a tag 'codigo_local_estoque' do método 'ListarLocaisEstoque' da API:
https://app.omie.com.br/api/v1/estoque/local/
para obter essa informação.

Preenchimento opcional.
obs_componente text
Observações do Componente.

componentes_kitArray

Este parâmetro é um array do tipo componentes_kit
