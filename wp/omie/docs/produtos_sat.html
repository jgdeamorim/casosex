Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ImportarCfeSat

Importa o XML de um CF-e SAT.

Parâmetros:
  ImportarSatRequest ImportarSatRequest
Importar CF-e SAT.
Retorno ImportarSatResponse:
Exemplo:
{
   "emiNome": "SeuPDV",
   "emiVersao": "1.01.02",
   "emiId": "PDV01",
   "chNFe": "",
   "satXml": "",
   "satMd5": "",
   "cAcaoCliente": "INCLUIR",
   "idCliente": 0,
   "idVendedor": 0,
   "idProjeto": 0,
   "idLocalEstoque": 0,
   "cNaoMovEstoque": "N",
   "cNaoGerarTitulo": "N",
   "cIncluirProduto": "N"
}

Tipos Complexos

ImportarSatRequest

Importar CF-e SAT.

emiNome string20
Nome do aplicativo emissor do cupom fiscal.
+
Preenchimento obrigatório.
O aplicativo deve ser previamente cadastrado. Para isso entre em contato com a nosso suporte.
emiVersao string20
Versão do aplicativo emissor do cupom fiscal.
+
Preenchimento obrigatório.
emiId string20
Identificação do computador onde o aplicativo emissor do cupom fiscal está instalado. É o código do PDV.
+
Exemplos: '01', '20', '55'.
Preenchimento obrigatório.
chNFe string44
Chave de Acesso do CF-e-SAT.
+
Preenchimento obrigatório.
satXml text
XML do Cupom Fiscal enviado.
+
Preechimento obrigatório.

Antes de enviar, converta os seus seguintes caracteres:

& para &amp;
> para &gt;
< para &lt;
" para &quot;
' para &apos;
| para &#124;

Após essa conversão aplique o MD5 para enviar no campo "nfceMd5".

Observação: Para requisições SOAP usar CDATA como demonstra o exemplo abaixo:
<![CDATA[Conteúdo do campo convertido]]>
satMd5 string32
MD5 do arquivo XML enviado em "satXml".
+
Preenchimento obrigatório.
cAcaoCliente string15
Ação a ser executada com relação a tag idCliente.
+
Preenchimento opcional.

Pode ser:

- CONSUMIDOR: assumirá que a venda foi realizada para um cliente consumidor padrão. Caso não exista um cliente consumidor cadastrado, o mesmo será criado automaticamente.

- ERRO (padrão): Exigirá a definição de um idCliente válido.

- INCLUIR: Com base nos dados do XML irá fazer a inclusão de um novo cliente.
idCliente integer
Código do cliente.
+
Preenchimento opcional.

- Se no XML não houver informações do cliente assumirá que a venda foi realizada para um cliente consumidor padrão. Caso não exista um cliente consumidor cadastrado, o mesmo será criado automaticamente.
 
- Se no XML houver informações do cliente, seus dados serão consultados no Omie com base no CPF/CNPJ, caso não seja encontrado a tag cAcaoCliente será avaliada.

Possível valores para tag cAcaoCliente:

- CONSUMIDOR: assumirá que a venda foi realizada para um cliente consumidor padrão. Caso não exista um cliente consumidor cadastrado, o mesmo será criado automaticamente.

- ERRO (padrão): Exigirá a definição de um idCliente válido.

- INCLUIR: Com base nos dados do XML irá fazer a inclusão de um novo cliente.
idVendedor integer
Código do vendedor.
+
Preenchimento opcional.

Quando não informado, será criado um vendedor padrão para o emissor de cupom fiscal.
idProjeto integer
Código do projeto.
+
Preenchimento opcional.

Quando não informado, será criado um projeto padrão para o emissor de cupom fiscal.
idLocalEstoque integer
Código do Local do Estoque.
+
Preenchimento opcional.

Caso não informado assumirá o Local de Estoque padrão.
cNaoMovEstoque string1
Indica que os items do Cupom Fiscal não devem movimentar o estoque.
+
Valores possíveis:
S - Sim
N - Não
cNaoGerarTitulo string1
Indica que a parcela não deve gerar um título no financeiro.
+
Valores possíveis:
S - Sim
N - Não
cIncluirProduto string1
Indica se na inclusão do cupom os produtos não existentes devem ser incluídos automaticamente.
+
Possíveis valores:
S - Sim
N - Não (padrão)

ImportarSatResponse

idImportacao integer
ID da Importação.
idCupom integer
Identificação do cupom fiscal.
idLote integer
Identificação do lote do cupom fiscal.
cCodStatus string4
Código do status de processamento do cupom fiscal.
+
Se retornar 0 indica que o cupom foi processado com sucesso.

Se retornar um valor maior que zero indica o código do erro gerado.
cDesStatus text
Descrição do status de processamento.
+
Caso ocorra erro, retorna a descrição do erro gerado.

omie_fail

code integer
Codigo do erro
description text
Descricao do erro
referer text
Origem do erro
fatal boolean
Indica se eh um erro fatal
