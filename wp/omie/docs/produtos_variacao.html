Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ConsultarVariacoes

Parâmetros:
  variacaoConsultarRequest variacaoConsultarRequest
Solicitação da consulta de variação.
Retorno variacaoConsultarResponse:
Exemplo:
{
  "nCodProd": 0,
  "cCodIntProd": ""
}

IncluirVariacoes

Parâmetros:
  variacaoIncluirRequest variacaoIncluirRequest
Solicitação da inclusão de variação para o produto.
Retorno variacaoIncluirResponse:
Exemplo:
{
   "nCodProd": 0,
   "cCodIntProd": "",
   "aCaracteristicas": [
      {
         "nIdCaract": 0
      }
   ],
   "aVariacoes": [
      {
         "nCodProdAssoc": 0,
         "cDescrProduto": "",
         "cCodProduto": "",
         "aValoresCaracteristicas": [
            {
               "nIdCaract": 0,
               "nIdValor": 0
            }
         ]
      }
   ]
}

ListarVariacoes

Parâmetros:
  variacaoListarRequest variacaoListarRequest
Solicitação para listar as variações.
Retorno variacaoListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50
}

Lista de aVariacoes

ident

nCodProd integer
Código do produto.
+
É o ID do produto e será utilizado apenas nas APIs como chave principal para localizar um produto.

Quando um produto for incluído via API, você receberá um ID para esse novo produto.
Recomendamos que você guarde essa informação no aplicativo que estiver integrando.

Utilize a tag "codigo_produto" do método "ListarProdutos" da API
/api/v1/geral/produtos/
para obter essa informação.
cCodIntProd string60
Código de integração do produto.
+
Preenchimento Opcional.

Esse campo deve ser informado apenas se você incluiu o produto via API e informou um código de integração para o produto. Do contrário, informe sempre a tag "nCodProd".
cCodProduto string60
Código do Produto exibido na tela de Produtos.
+
Preenchimento Opcional.
cDescrProduto string120
Descrição do produto.
+
Descrição do nome do produto no Omie.
