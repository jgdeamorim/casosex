Veja abaixo a documentação de cada método disponível para este serviço.

AlterarContaPagar

Altera uma conta a pagar

Parâmetros:

Cadastro de contas a pagar.
Retorno conta_pagar_cadastro_response: Resposta do Cadastro de Contas a Pagar
Exemplo:
{
   "codigo_lancamento_integracao": "1788304281",
   "codigo_cliente_fornecedor": 4214850,
   "data_vencimento": "01/09/2026",
   "valor_documento": 100.00,
   "codigo_categoria": "2.04.01",
   "data_previsao": "01/09/2026",
   "id_conta_corrente": 4243124
}

 "codigo_baixa": 0
