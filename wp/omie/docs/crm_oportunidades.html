Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarOportunidade

Parâmetros:
  opAlterarRequest opAlterarRequest
Solicitação de alteração de oportunidades
Retorno opAlterarResponse:
Exemplo:
{
   "identificacao": 
   {
       "nCodOp": 0,
       "cCodIntOp": "",
       "cDesOp": "",
       "nCodConta": 0,
       "nCodContato": 0,
       "nCodOrigem": 0,
       "nCodSolucao": 0,
       "nCodVendedor": 0
  }
}

ConsultarOportunidade

Consulta de oportunidade.

Parâmetros:
  opConsultarRequest opConsultarRequest
Solicitação de consulta de oportunidades.
Retorno opConsultarResponse: Resposta da consulta de oportunidades.
Exemplo:
{
  "nCodOp": 0,
  "cCodIntOp": ""
}

ExcluirOportunidade

Parâmetros:
  opExcluirRequest opExcluirRequest
Solicitação de exclusão de oportunidades.
Retorno opExcluirResponse:
Exemplo:
{
  "nCodOp": 0,
  "cCodIntOp": ""
}

IncluirOportunidade

Incluir uma oportunidade.

Parâmetros:
  opIncluirRequest opIncluirRequest
Solicitação de Inclusão de oportunidades
Retorno opIncluirResponse:
Exemplo:
{
    "identificacao": 
    {
        "cCodIntOp": "",
        "cDesOp": "",
        "nCodConta": 0,
        "nCodContato": 0,
        "nCodOrigem": 0,
        "nCodSolucao": 0,
        "nCodVendedor": 0
   }
}

ListarOportunidades

Lista de oportunidades.

Parâmetros:
  opListarRequest opListarRequest
Solicitação da listagem de oportunidades.
Retorno opListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}

UpsertOportunidade

Upsert de oportunidade.

Parâmetros:

Retorno opUpsertResponse: Resposta da upsert de oportunidades.
