ObterResumoContador

Obtem o resumo do painel do contador.

Parâmetros:
  resumopainelcontador_obterresumocontador_request resumopainelcontador_obterresumocontador_request
ObterResumoContador Request
Retorno resumopainelcontador_obterresumocontador_response: ObterResumoContador Response
Exemplo:
{
  "dDataInicio": "",
  "dDataFim": ""
}
