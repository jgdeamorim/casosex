Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarEtapaRecebimento

Alterar etapa recebimento NFe

Parâmetros:
  rcbtoAlterarEtapaRequest rcbtoAlterarEtapaRequest
Solicitação da alteração de etapa do recebimento da NFe
Retorno rcbtoAlterarEtapaResponse:
Exemplo:
{
   "nIdReceb" : 0,
   "cChaveNfe" : "",
   "cEtapa": ""
}

AlterarRecebimento

Alterar recebimento de NFe

Parâmetros:
  rcbtoAlterarRequest rcbtoAlterarRequest
Solicitação da alteração do recebimento da NFe
Retorno rcbtoAlterarResponse:
Exemplo:
{
   "ide": {
      "nIdReceb": 0,
      "cChaveNfe": ""
   },
   "itensRecebimentoEditar": {
      "itensIde": {
         "nSequencia": 0,
         "cAcao": "IGNORAR"
      }
   }
}

AlterarRecebimentoConcluido

Parâmetros:
  rcbtoConcAlterarRequest rcbtoConcAlterarRequest
Solicitação da alteração do recebimento da NFe
Retorno rcbtoConcAlterarResponse:
Exemplo:
{
   "ide": {
      "nIdReceb": 0,
      "cChaveNfe": ""
   },

      "cCategCompra": "",
      "nIdConta": 0,

   }
}

ListarRecebimentos

Listar recebimento de NFe

Parâmetros:

Reverter recebimento NFe
