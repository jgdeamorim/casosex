Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarDocumentos

Lista de XMLs de Documentos Fiscais.

Parâmetros:
  xmlListarDocumentosRequest xmlListarDocumentosRequest
Solicitação de listagem de XMLs de Documentos Fiscais.
Retorno xmlListarDocumentosResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 20,
  "cModelo": "55",
  "dEmiInicial": "",
  "dEmiFinal": ""
}

+
