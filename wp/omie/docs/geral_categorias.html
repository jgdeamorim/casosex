Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCategoria

Parâmetros:
  categoria_alterar categoria_alterar
Alteração de uma categoria.
Retorno categoria_cadastro_response: Status de retorno do cadastro da categoria.
Exemplo:
{
   "codigo": "",
   "descricao": "",
   "natureza": "",
   "tipo_categoria": "",
   "codigo_dre": "",
   "conta_inativa": ""
}

AlterarGrupoCategoria

Parâmetros:
  categoria_grupo_alterar categoria_grupo_alterar
Alteração de um grupo totalizador de categoria.
Retorno categoria_cadastro_response: Status de retorno do cadastro da categoria.
Exemplo:
{
   "codigo": "",
   "descricao": "",
   "natureza": ""
}

ConsultarCategoria

Consulta uma categoria

Parâmetros:
  categoria_consultar categoria_consultar
Consulta um código de categoria
Retorno categoria_cadastro: Cadastro de Categorias
Exemplo:
{
   "codigo": ""
}

IncluirCategoria

Parâmetros:
  categoria_incluir categoria_incluir
Inclusão de uma categoria.
Retorno categoria_cadastro_response: Status de retorno do cadastro da categoria.
Exemplo:
{
   "categoria_superior": "",
   "descricao": "",
   "natureza": "",
   "tipo_categoria": "",
   "codigo_dre": ""
}

IncluirGrupoCategoria

Parâmetros:
  categoria_grupo_incluir categoria_grupo_incluir
Inclusão de um grupo totalizador de categoria.
Retorno categoria_cadastro_response: Status de retorno do cadastro da categoria.
Exemplo:
{
   "descricao": "",
   "tipo_grupo": "",
   "natureza": ""
}

ListarCategorias

Lista as categorias cadastradas

Parâmetros:
  categoria_list_request categoria_list_request
Lista as categorias cadastradas.
Retorno categoria_listfull_response: Retorna a lista de categorias existentes no Omie.
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 50,
  "descricao": ""
}

Tipos Complexos

categoria_alterar

codigo string20
Código para a Categoria.
+
Informação obrigatória para o método AlterarCategoria.
descricao string50
Descrição para a Categoria
+
Informação obrigatória para os métodos IncluirCategoria e IncluirGrupoCategoria.
natureza string50
Descrição da Natureza da conta, equivalente ao campo "Observação" da categoria no ERP
tipo_categoria string3
Tipo de gasto/receita realizado com esta categoria
+
Para inclusão ou alteração essa informação pode ser obtida pela API:
/api/v1/geral/tipocategoria/
Utilizando o método ListarTipoCategoria, o código é retornado na tag "cCodigo"
Para que esse código seja válido, é necessário que:
Inclusão:
- "categoria_superior" começar com "1", então "cTipo" deve ser igual a "R"
- "categoria_superior" começar com "2", então "cTipo" deve ser igual a "P"

Alteração:
- "codigo" começar com "1", então "cTipo" deve ser igual a "R"
- "codigo" começar com "2", então "cTipo" deve ser igual a "P"
codigo_dre string10
Código no DRE (Demonstrativo de Resultados do Exercício)
+
Para inclusão ou alteração essa informação pode ser obtida pela API:
/api/v1/geral/dre/
Utilizando o método ListarCadastroDRE, o código é retornado na tag "codigoDRE"
Para que esse código seja válido, é necessário que:
- "nivelDRE" seja igual a 3
- "naoExibirDRE" seja igual a "N"
- "totalizaDRE" seja igual a "N"
conta_inativa string1
Indica que a categoria ou grupo de categoria está inativo.
