Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterDetalhesTarefa

Consulta os detalhes de uma tafera.

Parâmetros:
  ObterDetalhesTarefasRequest ObterDetalhesTarefasRequest
Consulta os detalhes de uma tafera.
Retorno ObterDetalhesTarefasResponse: Resposta da consulta de detalhes de uma tarefa.
Exemplo:
{
   "nIdOportunidade":0,
   "nIdTarefa":0
}

ObterListaTarefas

Parâmetros:
  ObterListaTarefasRequest ObterListaTarefasRequest
Solicitação da listagem do resumo das tarefas do CRM.
Retorno ObterListaTarefasResponse:
Exemplo:
{
   "dDia":"01/09/2026"
}

ObterResumoTarefas

Resumos das tarefas do CRM.

Parâmetros:
  obterResumoTarefasRequest obterResumoTarefasRequest
Solicitação do resumo das tarefas do CRM.
Retorno obterResumoTarefasResponse:
Exemplo:
{
   "dDataInicio":"01/09/2026",
   "dDataFim":"01/09/2026",
   "cTipoTarefa":""
}

cTipoTarefa string1
Código do tipo da tarefa.
+
O valor default desse campo é zero, o que significa que todas as listas serão retornadas.


Pode ser:
0 - Todas os resumos
1 - Apenas Tarefas Futuras
2 - Apenas Tarefas para Hoje
3 - Apenas Tarefas em Execução
4 - Apenas Tarefas Realizadas
9 - Apenas Tarefas Totalizadas
