Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ObterCTe

Parâmetros:
  ObterCTeRequest ObterCTeRequest
Solicita as informações de um CTe.
Retorno ObterCTeResponse:
Exemplo:
{
   "nIdCTe": 0
}

ObterCupom

Parâmetros:

Tipos Complexos

ObterCTeRequest

nIdCTe integer
ID do Conhecimento de Transporte

ObterCTeResponse

cNumCTe text
Número do CTe.
nChaveCTe string44
Chave do CTe.
dDataEmisCTe string10
Data da emissão do CTe.
cModeloCTe string2
Modelo do CTe.
cXmlCTe text
XML do CTe.
cPdf text
Link do PDF do Danfe simplificado.
cLinkPortal text
Link para acessar os documentos no portal Omie.
cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDesStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
