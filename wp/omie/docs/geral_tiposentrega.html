Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarTipoEntrega

Alterar tipo de entrega

Parâmetros:
  teAlterarRequest teAlterarRequest
Requisição de alteração de tipo de entrega
Retorno teAlterarResponse:
Exemplo:
{
  "nCodEntrega": 0,
  "cCodIntEntrega": "",
  "cDescricao": "",
  "cInativo": "N" 
}

ConsultarTipoEntrega

Consultar tipo de entrega

Parâmetros:
  teConsultarRequest teConsultarRequest
Requisição de consulta de tipo de entrega
Retorno teConsultarResponse: Resposta da consulta de tipo de entrega
Exemplo:
{
  "nCodEntrega": 0,
  "cCodIntEntrega": ""
}

ExcluirTipoEntrega

Excluir tipo de entrega

Parâmetros:
  teExcluirRequest teExcluirRequest
Requisição de exclusão de tipo de entrega
Retorno teExcluirResponse:
Exemplo:
{
  "nCodEntrega": 0,
  "cCodIntEntrega": ""
}

IncluirTipoEntrega

Incluir tipo de entrega

Parâmetros:
  teIncluirRequest teIncluirRequest
Requisição de inclusão de tipo de entrega
Retorno teIncluirResponse:
Exemplo:
{
  "nCodTransp": 0,
  "cCodIntEntrega": "",
  "cDescricao": "",
  "cInativo": "N" 
}

ListarTipoEntrega

Listar tipo de entrega

Parâmetros:
  teListarRequest teListarRequest
Requisição de listagem de tipos de entrega
Retorno teListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegistrosPorPagina": 50,
  "nCodTransp": 0
}
