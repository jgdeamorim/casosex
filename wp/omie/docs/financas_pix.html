Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

CancelarPix

Efetua o cancelamento de um PIX

Parâmetros:
  CancelarPixRequest CancelarPixRequest
Solicitação do cancelamento do PIX.
Retorno CancelarPixResponse:
Exemplo:
{
   "nIdPix": 0,
   "cCodIntPix": ""
}

GerarPix

Gera o QrCode de um PIX.

Parâmetros:
  GerarPixRequest GerarPixRequest
Gera um QrCode para pagamento PIX.
Retorno GerarPixResponse:
Exemplo:
{
   "cCodIntPix": "1670867357",
   "nIdCliente": 0,
   "vValor": 1.99,
   "nIdConta": 0,
   "cUrlNotif": ""
}

GerarQrCodePix

Parâmetros:
  GerarQrCodePixRequest GerarQrCodePixRequest
Gera um QrCode estático para pagamentos PIX.
Retorno GerarQrCodePixResponse:
Exemplo:
{
   "nIdConta": 0
}

ListarPix

Parâmetros:
  ListarPixRequest ListarPixRequest
Solicitação da listagem de detalhes do PIX.
Retorno ListarPixResponse:
Exemplo:
{
   "nPagina": 1,
   "nRegPorPagina": 50
}

ListarStatusPix

Parâmetros:
  ListarStatusPixRequest ListarStatusPixRequest
Solicitação da listagem de status do PIX.
Retorno ListarStatusPixResponse:
Exemplo:
{
   "nPagina": 1,
   "nRegPorPagina": 50
}

ObterPix

Parâmetros:
  ObterPixRequest ObterPixRequest
Solicitação dados do PIX.
Retorno ObterPixResponse: Detalhes do PIX.
Exemplo:
{
   "nIdPix": 0,
   "cCodIntPix": "",
   "nCodTitulo": 0
}

ObterStatusPix

Parâmetros:
  ObterStatusPixRequest ObterStatusPixRequest
Solicitação de Status do PIX.
Retorno ObterStatusPixResponse:
Exemplo:
{
   "nIdPix": 0,
   "cCodIntPix": "",
   "nCodTitulo": 0
}

nIdPix integer
ID do lançamento PIX.
+
O conteúdo desse campo é o código interno gerado pelo Omie ao gerar o PIX.

Esse campo não é exibido na tela do Omie, mas é a chave de integração via API.
É uma informação interna, utilizada apenas nas APIs.
cCodIntPix string60
Código do lançamento gerado pelo integrador.
+
Preenchimento obrigatório para o método 'GerarPix'.
lDel boolean
Indica se a conta a receber será excluída
+
ao efetuar o cancelamento do PIX.

Ao ser preenchida com true a conta a receber que gerou o PIX será excluída.

Pode ser:
false
true

Default: true

CancelarPixResponse

cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDescStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.

GerarPixRequest

Gera um QrCode para pagamento PIX.

cCodIntPix string60
Código do lançamento gerado pelo integrador.
+
Preenchimento obrigatório para o método 'GerarPix'.
nCodTitulo integer
ID da conta a receber que irá gerar o PIX.
+
Caso essa tag não seja preenchida uma nova conta a receber será gerada.


Preenchimento opcional.
vValor decimal
Valor do PIX.
+
Preenchimento obrigatório para o método 'GerarPix'.
nIdConta integer
Código da Conta Corrente.
+
Preenchimento Opcional.

Caso não informado, assumirá a conta omie.CASH

Utilize a tag 'codigo' do método 'PesquisarContaCorrente' da API
/api/v1/geral/contacorrente/
para obter essa informação.
cUrlNotif text
URL de CallBack que será acionada quando o pagamento for efetuado.
+
Preenchimento opcional.
nIdCliente integer
Código do cliente.
+
Informação utilizada para identificar o cadastro do Cliente.

Utilize a tag 'codigo_cliente_omie' do método 'ListarClientes' da API
/api/v1/geral/clientes/
para obter essa informação.

Preenchimento opcional.

Quando as tags 'cIdCliente' e cCnpjCpf' não informadas, assumirá que o PIX foi realizado para um cliente consumidor padrão.

Caso não exista um cliente consumidor cadastrado, o mesmo será criado automaticamente.

Essa tag não deve ser preenchida quando a tag 'nCodTitulo' for informada.
cCnpjCpf string20
CNPJ/CPF do cliente.
+
Informação utilizada para identificar o cadastro do Cliente.

Utilize a tag 'cbpj_cpf' do método 'ListarClientes' da API
/api/v1/geral/clientes/
para obter essa informação.

Preenchimento opcional.

Quando as tags 'cIdCliente' e cCnpjCpf' não informadas, assumirá que o PIX foi realizado para um cliente consumidor padrão.

Caso não exista um cliente consumidor cadastrado, o mesmo será criado automaticamente.
