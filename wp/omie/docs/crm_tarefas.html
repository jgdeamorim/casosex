Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarTarefa

Altera uma tarefa.

Parâmetros:
  tarefaAlterarRequest tarefaAlterarRequest
Solicitação de alteração de tarefa de uma oportunidade.
Retorno tarefaAlterarResponse:
Exemplo:
{
   "nCodTarefa":0,
   "nCodOp":0,
   "cCodInt":"",
   "nCodUsuario":425605408,
   "dData":"01/09/2026",
   "cHora":"10:15",
   "nCodNotif":99999,
   "nCodAtividade":1,
   "cDescricao":"Descricao"
}

CalendarioTarefas

Parâmetros:
  tarefa_ics_request tarefa_ics_request
Request Calendar Events (ICS)
Retorno tarefa_ics_response: Response Calendar Events (ICS)
Exemplo:
{
   "email_vend":"omie@omie.com.br",
   "calendar_key":"9bbd473104936d521d364abdc6a0d1a5"
}

ConsultarTarefa

Consulta uma tarefa da oportunidade.

Parâmetros:
  tarefaConsultarRequest tarefaConsultarRequest
Solicitação da consulta da tarefa de uma oportunidade.
Retorno tarefaConsultarResponse:
Exemplo:
{
   "nCodTarefa":0,
   "nCodOp":0,
   "cCodInt":""
}

ExcluirTarefa

Exclui um tarefa.

Parâmetros:
  tarefaConsultarRequest tarefaConsultarRequest
Solicitação da consulta da tarefa de uma oportunidade.
Retorno tarefaExcluirResponse:
Exemplo:
{
   "nCodTarefa":0,
   "nCodOp":0,
   "cCodInt":""
}

IncluirTarefa

Inclui uma tarefa na oportunidade.

Parâmetros:
  tarefaIncluirRequest tarefaIncluirRequest
Solicitação de inclusão de tarefa de uma oportunidade.
Retorno tarefaIncluirResponse:
Exemplo:
{
   "nCodOp":0,
   "cCodInt":"",
   "nCodUsuario":425605408,
   "dData":"01/09/2026",
   "cHora":"10:15",
   "nCodNotif":99999,
   "nCodAtividade":1,
   "cDescricao":"Descricao"
}

ListarEmailsTarefas

Lista os emails tarefas.

Parâmetros:
  tarefaEmailListarRequest tarefaEmailListarRequest
Solicitação da listagem de emails "tarefas" da oportunidade.
Retorno tarefaEmailListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}

ListarTarefas

Tarefas da oportunidade.

Parâmetros:
  tarefaListarRequest tarefaListarRequest
Solicitação da listagem de tarefas da oportunidade.
Retorno tarefaListarResponse:
Exemplo:
{
  "pagina": 1,
  "registros_por_pagina": 20
}

UpsertTarefa

Parâmetros:
  tarefaUpsertRequest tarefaUpsertRequest
Solicitação de inclusão/alteração de tarefa de uma oportunidade.
Retorno tarefaUpsertResponse:
Exemplo:
{
