Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ListarMovimentos

Parâmetros:
  mfListarRequest mfListarRequest
Solicitação de Listagem da movimentação financeira (Contas a Pagar, Contas a Receber e Lançamentos do Conta Corrente).
Retorno mfListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 500
}
