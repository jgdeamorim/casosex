ConsultarTipoDocumento

Parâmetros:
  tipo_documento_consultar tipo_documento_consultar
Pesquisa um tipo de documento por código
Retorno tipo_documento_cadastro: Cadastro de tipos de documentos
Exemplo:
{
  "codigo":"9999"
}

PesquisarTipoDocumento

Pesquisa o tipo de documento

Parâmetros:
  tipo_documento_pesquisa_request tipo_documento_pesquisa_request
Pesquisa do tipo de documento
Retorno tipo_documento_pesquisa_response: Resposta da pesquisa,
Exemplo:
{
   "codigo": ""
}
