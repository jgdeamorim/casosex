Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCaracteristica

Parâmetros:
  caractAlterarRequest caractAlterarRequest
Altera uma característica de produto.
Retorno caractAlterarResponse:
Exemplo:
{
   "nCodCaract": 0,
   "cCodIntCaract": "",
   "cNomeCaract": ""
}

ConsultarCaracteristica

Parâmetros:
  caractConsultarRequest caractConsultarRequest
Consulta uma característica de produto.
Retorno caractConsultarResponse:
Exemplo:
{
  "nCodCaract": 0,
  "cCodIntCaract": ""
}

ExcluirCaracteristica

Parâmetros:
  caractExcluirRequest caractExcluirRequest
Exclui uma característica de produto.
Retorno caractExcluirResponse:
Exemplo:
{
   "nCodCaract": 0,
   "cCodIntCaract": ""
}

IncluirCaracteristica

Parâmetros:
  caractIncluirRequest caractIncluirRequest
Inclui uma característica de produto.
Retorno caractIncluirResponse:
Exemplo:
{
   "cCodIntCaract": "CPROD1788306292",
   "cNomeCaract": ""
}

ListarCaracteristicas

Parâmetros:
  caractListarRequest caractListarRequest
Listagem de características de produtos.
Retorno caractListarResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50
}

Tipos Complexos

caractAlterarRequest

nCodCaract integer
Código da característica de produto.
+
(Interno, utilizado apenas na integração via API, não é exibido na tela).
O conteúdo desse campo é o código interno da característica do produto gerado pelo Omie.
cCodIntCaract string60
Código de integração da característica do produto.
+
(Interno, utilizado apenas na Integração via API, não aparece na tela).
Utilize esse campo para informar o código da característica utilizado no seu aplicativo quando incluir uma característica no Omie.
Assim, poderá utilizar esse campo para resgatar as informações da característica desejada.
Caso informe esse campo, não informe a tag nCodCaract. Caso isso aconteça, o conteúdo dessa tag será desconsiderada.
cNomeCaract string30
Nome da característica.
+
(Não será permitida a inclusão de mais de uma característica com a mesma descrição.
cValorDef string1
Definir os conteúdos possíveis para essa característica (S/N).
+
Como padrão o valor é "N".
conteudosPermitidos conteudosPermitidosArray
Lista com os possíveis conteúdos para uma característica.
