Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AdicionarPedido

Parâmetros:
  AdicionarPedidoRequest AdicionarPedidoRequest
Estrutura para Inclusão de Pedido de Venda
Retorno AdicionarPedidoResponse:
Exemplo:
{
   "codigo_pedido_integracao":"123456",
   "codigo_cliente":45621546,
   "codigo_cenario_impostos":65468465,
   "itens":[
      {
         "codigo_produto":0,
         "quantidade":1,
         "valor_unitario":1,
         "cfop":"",
         "codigo_cenario_impostos_item":0
      }
   ]
}

AlterarItemPedido

Altera um item no pedido de venda.

Parâmetros:
  alterarItemPedidoRequest alterarItemPedidoRequest
Solicitação de Alteração de um item no Pedido de Venda
Retorno alterarItemPedidoResponse:
Exemplo:
{
   "codigo_pedido": 0,
   "codigo_item_integracao": "",
   "codigo_item": 0,
   "codigo_produto": 0,
   "quantidade": 1,
   "valor_unitario": 1
}

ExcluirItemPedido

Exclui um item no pedido de venda.

Parâmetros:
  excluirItemPedidoRequest excluirItemPedidoRequest
Solicitação de Exclusão de um item no Pedido de Venda.
Retorno excluirItemPedidoResponse:
Exemplo:
{
   "codigo_pedido": 0,
   "codigo_item_integracao": "",
   "codigo_item":0
}

ExcluirItensPedido

Exclui todos os itens do pedido de venda.

Parâmetros:
  excluirItensPedidoRequest excluirItensPedidoRequest
Solicitação de Exclusão de todos os itens no Pedido de Venda.
Retorno excluirItensPedidoResponse:
Exemplo:
{
   "codigo_pedido": 0
}

IncluirItemPedido

Inclui um item no pedido de venda.

Parâmetros:
  incluirItemPedidoRequest incluirItemPedidoRequest
Solicitação da inclusão de um Item no Pedido de Venda.
Retorno incluirItemPedidoResponse:
Exemplo:
{
   "codigo_pedido": 0,
   "codigo_item_integracao": "",
   "codigo_produto": 0,
   "quantidade": 1,
   "valor_unitario": 1,
   "cfop": "",
   "codigo_cenario_impostos_item": 0
}

TotalizarPedido

Recalcula os totais do pedido de venda.

Parâmetros:
  totalizarPedidoRequest totalizarPedidoRequest
Realiza a totalização do pedido de venda.
Retorno totalizarPedidoResponse:
Exemplo:
{
   "codigo_pedido": 0
}

Tipos Complexos

AdicionarPedidoRequest

codigo_pedido_integracao string60
Código de integração do pedido de venda.
+
Preenchimento Obrigatório na inclusão/alteração.
Preenchimento Opcional na Consulta/Pesquisa.

Preencha esse campo com o código do pedido no aplicativo que você está integração com o Omie. A função dele é servir como uma mapa de relacionamento entre as aplicações. Ao realizar uma consulta/listagem de pedidos você conseguirá ver a relação entre o id do pedido gerado no Omie e o código de pedido existente em sua aplicação.
codigo_cliente integer
Código do cliente.
+
Preenchimento Obrigatório.

/api/v1/geral/clientes/
para obter essa informação.
codigo_cliente_integracao string60
Código de Integração do Cliente
+
Preenchimento Opcional.

Esse campo deve ser informado apenas se você incluiu o cliente via API e informou um código de integração para o cliente. Do contrário, informe sempre a tag "codigo_cliente".
data_previsao string10
Data de Previsão de Faturamento.
+
Preenchimento Obrigatório.

Utilize o formato "dd/mm/aaaa".

Esse campo indica a data da previsão do faturamento do pedido e deve ser informado com uma data igual ou superior a data corrente.
etapa string2
Etapa do pedido de venda.
+
Preenchimento Obrigatório.

Esse campo indica em que coluna o pedido de venda irá figurar no processo de faturamento do Omie.

Utilize a tag "codigo" do método "ListarEtapasFaturamento" da API
/api/v1/produtos/etapafat/
para obter essa informação.

Os valores são fixos, mas as descrições (funções atribuídas a cada coluna pode mudar. A API irá indicar a descrição de cada coluna.

Os valores disponíveis para esse campo podem ser:

"10" - Primeira coluna
"20" - Segunda coluna
"30" - Terceira coluna
"40" - Quarta coluna
"50" - Faturar
