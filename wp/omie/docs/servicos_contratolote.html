Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

FaturarLoteContrato

Parâmetros:
  FaturarLoteContratoRequest FaturarLoteContratoRequest
Faturar Contrato de Serviço em lote
Retorno FaturarLoteContratoResponse:
Exemplo:
{
   "cCodIntLote":"9999999"
}

ListarLotesContrato

Parâmetros:
  ListarLotesContratoRequest ListarLotesContratoRequest
Listar status de faturamento dos Contratos de Serviço a partir das datas de processamento.
Retorno ListarLotesContratoResponse:
Exemplo:
{
   "dDtIncDe":"01/09/2026",
   "dDtIncAte":"01/09/2026"
}

StatusLoteContrato

Status do lote faturado a partir do ID.

Parâmetros:
  StatusLoteContratoRequest StatusLoteContratoRequest
Obtém o status do Lote do Contrato de Serviço
Retorno StatusLoteContratoResponse:
Exemplo:
{
    "nIdLoteFat":45223245
}

FaturarLoteContratoResponse

nQtdeFat integer
Qtde de contratos de serviços faturados.
nIdLoteFat integer
Id do Lote de Processamento
cCodStatus string4
Código do status do processamento.
+
Se o retorno for '0' significa que a solicitação foi executada com sucesso.
Se o retorno for maior que '0' ocorreu algum erro durante o processamento da solicitação.
A tag 'cDesStatus' descreve o problema ocorrido.
cDesStatus text
Descrição do status do processamento.
+
Essa tag explica o resultado da tag 'cCodigoStatus'.
