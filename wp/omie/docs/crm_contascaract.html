Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCaractConta

Parâmetros:
  AlterarCaractCRMContaRequest AlterarCaractCRMContaRequest
Altera uma característica de uma conta
Retorno AlterarCaractCRMContaResponse:
Exemplo:
{
  "nCod": 0,
  "cCodInt": "",
  "campo": "",
  "conteudo": ""
}

ConsultarCaractConta

Parâmetros:
  ConsultarCaractCRMContaRequest ConsultarCaractCRMContaRequest
Consulta todas as características de uma conta.
Retorno ConsultarCaractCRMContaResponse:
Exemplo:
{
  "nCod": 0,
  "cCodInt": ""
}

ExcluirCaractConta

Parâmetros:
  ExcluirCaractCRMContaRequest ExcluirCaractCRMContaRequest
Exclui uma característica de uma contar.
Retorno ExcluirCaractCRMContaResponse:
Exemplo:
{
  "nCod": 0,
  "cCodInt": "",
  "campo": ""
}

ExcluirTodasCaractConta

Parâmetros:
  ExcluirTodasCaractCRMContaRequest ExcluirTodasCaractCRMContaRequest
Exclui todas as características de uma conta.
Retorno ExcluirTodasCaractCRMContaResponse:
Exemplo:
{
  "nCod": 0,
  "cCodInt": ""
}

IncluirCaractConta

Parâmetros:
  IncluirCaractCRMContaRequest IncluirCaractCRMContaRequest
Inclui uma característica para uma conta
Retorno IncluirCaractCRMContaResponse:

  "nCod": 0,
