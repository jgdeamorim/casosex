ObterResumoServicos Request

dDataInicio string10
Data Inicial de Consulta.
dDataFim string10
Data final de Consulta.
lApenasResumo boolean
Exibir apenas o resumo.Quando true será retornado as estruturas:OrdemServico->faturarHojeContratoServico->faturarHojeQuando false retornará todas as estruturas.Default = true
