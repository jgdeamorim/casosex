Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

ConsultarAnexo

Parâmetros:
  docConsultarAnexoRequest docConsultarAnexoRequest
Consulta o anexo de um documento.
Retorno docConsultarAnexoResponse:
Exemplo:
{
   "cCodIntAnexo": "",
   "cTabela": "",
   "nId": 0,
   "nIdAnexo": 0,
   "cNomeArquivo": ""
}

ExcluirAnexo

Parâmetros:
  docExcluirAnexoRequest docExcluirAnexoRequest
Exclui um anexo de um Documento.
Retorno docExcluirAnexoResponse:
Exemplo:
{
   "cCodIntAnexo": "",
   "cTabela": "",
   "nId": 0,
   "nIdAnexo": 0,
   "cNomeArquivo": ""
}

IncluirAnexo

Inclui o anexo para um documento.

Parâmetros:
  docIncluirAnexoRequest docIncluirAnexoRequest
Inclui um anexo de um Documento.
Retorno docIncluirAnexoResponse:
Exemplo:
{
  "cCodIntAnexo": "",
  "cTabela": "",
  "nId": 0,
  "cNomeArquivo": "",
  "cTipoArquivo": "",
  "cArquivo": "",  
  "cMd5": ""
}

ListarAnexo

Parâmetros:
  docListarAnexosRequest docListarAnexosRequest
Solicitação de listagem de anexos de um Documento.
Retorno docListarAnexosResponse:
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 50,
  "nId": 0,
  "cTabela":""
}

Parâmetros:
  docObterAnexoRequest docObterAnexoRequest

Tipos Complexos

docConsultarAnexoRequest

Consulta o anexo de um documento.

cCodIntAnexo string20
Código de integração do anexo.
+
(Interno, utilizado apenas na integração via API, não é exibido na tela).
Utilize esse campo para informar o código do anexo utilizado no seu aplicativo quando incluir o anexo no Omie.
Assim, poderá utilizar esse campo para resgatar o anexo desejado.
cTabela string100
Nome da tabela onde o anexo está incluído.
+
Pode ser:
cliente
produto
servico
pedido-venda
remessa-produto
ordem-servico
contrato-servico
pedido-compra
nota-entrada
ordem-producao
conta-pagar
conta-receber
conta-corrente
conta-corrente-lancamento
crm-contas
crm-contatos
crm-oportunidades
com-recebimento
nId integer
ID do documento de acordo com a tabela especificada.
+
Por exemplo:
Caso você informe "cliente" na tag "cTabela" você deve informar o ID do cliente neste campo.

Preenchimento obrigatório.
nIdAnexo integer
ID do anexo.
+
Gerado automático na inclusão.
Informe esse campo para Obter, Consultar e Excluir o anexo.
cNomeArquivo string100
Nome do arquivo que foi adicionado.
+
Preencha essa tag, apenas se você não tiver ou souber qual é o código de integração do anexo (tag cCodIntAnexo).
Caso a tag cCodIntAnexo esteja preenchida, o conteúdo dessa tag será desconsiderado.
