Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarEstrutura

Alterar a estrutura de um produto.

Parâmetros:
  malhaAlterarRequest malhaAlterarRequest
Alteração de item da estrutura do produto.
Retorno malhaAlterarResponse:
Exemplo:
{
   "idProduto": 0,
   "intProduto": "",
   "itemMalhaAlterar" : [
      {
         "idMalha": 0,
         "intMalha": "",
         "idProdMalha": 0,
         "intProdMalha": "",
         "quantProdMalha": 0,
         "percPerdaProdMalha": 0,
         "obsProdMalha": ""
      }
   ]
}

ConsultarEstrutura

Consulta a estrutura do produto.

Parâmetros:
  malhaConsultarRequest malhaConsultarRequest
Consulta uma malha/estrutura de um produto.
Retorno malhaConsultarResponse:
Exemplo:
{
   "idProduto": 0,
   "intProduto": "",
   "codProduto": ""
}

ExcluirEstrutura

Excluir item da estrutura de um produto.

Parâmetros:
  malhaExcluirRequest malhaExcluirRequest
Exclusão de um item da estrutura de um produto.
Retorno malhaExcluirResponse:
Exemplo:
{
   "idProduto": 0,
   "intProduto": "",
   "idMalha": 0,
   "intMalha": ""
}

IncluirEstrutura

Parâmetros:
  malhaIncluirRequest malhaIncluirRequest
Inclusão de item da estrutura do produto.
Retorno malhaIncluirResponse:
Exemplo:
{
   "idProduto": 0,
   "intProduto": "",
   "itemMalhaIncluir" : [
      {
         "intMalha": "",
         "idProdMalha": 0,
         "intProdMalha": "",
         "quantProdMalha": 0,
         "percPerdaProdMalha": 0,
         "obsProdMalha": ""
      }
   ]
}

ListarEstruturas

Lista as estruturas de produtos.

Parâmetros:
  malhaPesquisarRequest malhaPesquisarRequest
Solicitação de Listagem de estruturas de produtos.
Retorno malhaPesquisarResponse: Resultado da pesquisa de estrutura de produtos.
Exemplo:
{
  "nPagina": 1,
  "nRegPorPagina": 100
}
