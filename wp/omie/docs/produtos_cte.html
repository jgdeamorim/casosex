Métodos

Veja abaixo a documentação de cada método disponível para este serviço.

AlterarCte

Parâmetros:
  cte_alterar_request cte_alterar_request
Estrutura de requisição da alteração do CT-e.
Exemplo:
{
  "nIdCte": 123456,
  "cCategoria": "1.01.01",
  "nVendedor": 0,
  "nProjeto": 0
}

AverbacaoCTe

Parâmetros:
  cteAverbacaoRequest cteAverbacaoRequest
Solicitação de Averbação do CT-e.
Retorno cteAverbacaoResponse:
Exemplo:
{
   "cAppNome": "GeradorCTe",
   "cAppVersao": "1.01.02",
   "cAppId": "Cte01",
   "cChaveCte": "",
   "cXmlCteAverb": "",
   "cMd5CteAverb": ""
}

CancelarCTe

Cancela um CT-e.

Parâmetros:
  cteCancelarRequest cteCancelarRequest
Solicitação de Cancelamento de CT-e.
Retorno cteCancelarResponse:
Exemplo:
{
   "cAppNome": "GeradorCTe",
   "cAppVersao": "1.01.02",
   "cAppId": "Cte01",
   "cChaveCte": "",
   "cXmlCteCanc": "",
   "cMd5CteCanc": ""
}

CartaCorrecaoCTe

Parâmetros:
  cteCCRequest cteCCRequest
Solicitação de Carta de Correção do CT-e.
Retorno cteCCResponse:
Exemplo:
{
   "cAppNome": "GeradorCTe",
   "cAppVersao": "1.01.02",
   "cAppId": "Cte01",

   "cMd5CteCC": ""

ExcluirCTe

Parâmetros:
  cteExcluirRequest cteExcluirRequest
Estrutura para excluir o CT-e.
Retorno cteExcluirResponse:
Exemplo:
{
   "nIdCte": 0
}

ExcluirFaturaCTe

Exclui uma fatura de um grupo de CT-es.

Parâmetros:
  cteExcluirFatRequest cteExcluirFatRequest
Solicitação da exclusão do faturamento de um grupo de CT-es.
Retorno cteExcluirFatResponse:
Exemplo:
{
   "cAppNome": "GeradorCTe",
   "cAppVersao": "1.01.02",
   "cAppId": "Cte01",
   "nIdFaturamento": 0
}

FaturarCTe

Gera uma fatura para um grupo de CT-es.

Parâmetros:
  cteFaturarRequest cteFaturarRequest
Solicitação do faturamento de um grupo de CT-es.
Retorno cteFaturarResponse:
Exemplo:
{
   "cAppNome": "GeradorCTe",
   "cAppVersao": "1.01.02",
   "cAppId": "Cte01",
   "CNPJCliente": "",
   "cCategoria": "1.01.02",
   "nContaCorrente": 0,
   "dVencimento": "",
   "nValorFatura": 100,
   "itensFatura": [
      {
         "nSeq": 1,
         "cChaveCte": "",
         "nValorCte": 30
      },
      {
         "nSeq": 2,
         "cChaveCte": "",
         "nValorCte": 70
      }
   ]
}

         "nSeq": 2,

      }

ListarNFeTransp

Parâmetros:
  cteListarNFeRequest cteListarNFeRequest

Parâmetros:

  "cAppId": "Cte01",

nIdFaturamentoLote integer
Id do faturamento.
+
Para indicar o início de um novo lote envie 0 (zero) nesse campo.

Como resposta você receberá o nIdFaturamento gerado pelo Omie automaticamente.

Nos próximos envios informe o nIdFaturamento recebido para adicionar novos CTes ao lote.

Para concluir o envio de CTes e gerar a fatura do lote informe "S" na tag cConcluirFatura.

Na última chamada desse método você pode enviar apenas a tag cConcluirFatura. Opcionalmente, você pode enviar os CTes restantes.
cConcluirFatura string1
Concluir o faturamento.
+
Indica que o envio de CTes está concluído para o lote e que pode realizar o faturamento do mesmo.

Possíveis valores:

S - Sim, encerra o processo de envio de CTes e realiza o faturamento. Nesse momento, você deve informar as tags CNPJCliente, cCategoria, nContaCorrente, dVencimento e nValorFatura e complementar com as tags cNumeroFatura e departamentos, se necessário.

N - Não, indica que uma lista de CTes deve ser adicionada ao lote. As tags cCategoria, nContaCorrente, dVencimento, nValorFatura, cNumeroFatura e departamentos não devem ser ser informadas.
CNPJCliente string20
CNPJ do Cliente.
+
Preenchimento obrigatório.

Código da Categoria
nContaCorrente integer
Id da Conta Corrente no Omie para a geração do título no financeiro.

Data de Exclusão.

Valor da Fatura.
+
Preenchimento Obrigatório.
cNumeroFatura string20
Número da Fatura.
cListaChavesCTes text
Lista de chave de CTes.
+
As chaves devem ser informadas com o separador | (carácter pipe).
itensFaturaLote itensFaturaLoteArray
Itens da Fatura.
departamentos departamentosArray
Distribuição por Departamentos.

Preenchimento opcional.
